## 物語の設計

14.1では、モデルを選ぶ単位で予測が変わった。14.2では、異なるデータで学習したモデルの**予測そのもの**を平均する。全編の問いは「同じ入力で5本の回帰モデルがばらばらに外したとき、平均すれば誤差は必ず5分の1になるのか」。冒頭に説明用の回帰問題の入力 $x=0.45$ を置き、5本の予測が約0.786〜1.112に広がる一方、平均は約0.965、既知の生成関数の値は約0.949と見せる。なぜ近づいたのか、そして5分の1を期待してよいのかを予想させる。

1つの訓練集合から重複を許して標本を引き直し、5つのブートストラップ集合を作る。各集合で同じ種類の多項式回帰を学習し、曲線のずれを同じ軸上で比べる。1点の成功から入力全体の二乗誤差へ進み、モデル間の誤差の違いが平均化で消える様子を面積と棒で見せる。互いに無相関なら $E_{\rm COM}=E_{\rm AV}/M$ となる条件を、共通のずれを持つ場合の実験で崩す。最後に同じ $x=0.45$ の5本と平均へ戻り、「改善したが5分の1とは限らない」という問いに答える。次節の逐次的な重み付けへ問いを渡す。

式だけの画面を続けず、すべての式を曲線、予測点、誤差棒と一緒に置く。軸に装飾枠を置かない。色は入力・元の量を青、平均・結果を緑、演算を黄、比較を紫、誤差を赤に統一する。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning*, §14.2 印刷pp.655–657（PDF pp.675–677）を `pdftotext -layout` で全文確認し、3ページの画像も確認した。この節の独立した図はない。式(14.7)–(14.14)と、§3.2 の Fig.3.5（印刷p.150）と§1.2.3 のブートストラップ標本（印刷p.23）を参照する。[公式正誤表（2011-09-21）](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)を確認し、印刷pp.655–657と式(14.7)–(14.14)に訂正はない。p.659以降の訂正は次節14.3に属する。

式(14.9)–(14.13)の逐行の展開は映像では追わず、同じ入力での恒等式 $E_{\rm AV}-E_{\rm COM}=E_x[M^{-1}\sum_m(y_m-y_{\rm COM})^2]\ge0$ を点と棒で示す。(14.14)の$1/M$は別の無相関実験で示し、条件のない一般則として扱わない。原典の§14.3以降のAdaBoostの手順は次節へ送る。

## 数値例と近似の条件

説明用の自作データ。生成関数は $h(x)=\sin(2.2x)+0.25x$、入力は区間 $[-1,1]$ の12点、観測ノイズは NumPy RNG seed 3 の正規乱数（標準偏差0.18）。NumPy RNG seed 203で復元抽出した5つの12点集合を使い、5次のLegendre多項式と固定した二次正則化で学習する。冒頭の $x=0.45$ における生成関数の値は0.948525979。5予測は順に1.096065904、1.020397343、0.812950594、0.785935090、1.111694066で、平均は0.965408599。最も近い単独予測の絶対誤差は約0.07187、平均の絶対誤差は約0.01688。全入力の平均二乗誤差は区間上の一様な501点格子を離散入力分布として計算する。個別の平均は0.084512039、コミッティは0.025843186、比は0.305793、差は予測間の散らばり0.058668853と一致する。生成関数は動画の答え合わせ用に既知とする。実問題で未知の真値を使って学習するわけではない。無相関の実験は別の説明用の誤差関数として明示し、ブートストラップの5本が無相関だとは仮定しない。説明用実験では $u=(x+1)/2$ の一様分布で、互いに直交する周波数1〜5の $\sqrt2\cos(2\pi mu)$ を個別誤差、周波数6を共通誤差とする。$\epsilon_m=\sqrt{\rho}c+\sqrt{1-\rho}v_m$ なら各誤差の分散は1、異なる誤差の相関は $\rho$、コミッティの誤差は $\rho+(1-\rho)/5$。$\rho=0$ で0.2、$\rho=0.8$ で0.84、$\rho=1$ で1。これはバギングの5本の実測相関ではない。

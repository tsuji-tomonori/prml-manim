# PRML 14.2 コミッティ

## 物語の設計

14.1では、モデルを選ぶ単位で予測が変わった。14.2では、異なるデータで学習したモデルの**予測そのもの**を平均する。全編の問いは「同じ入力で5本の回帰モデルがばらばらに外したとき、平均すれば誤差は必ず5分の1になるのか」。冒頭に説明用の回帰問題の入力 $x=0.45$ を置き、5本の予測が約0.786〜1.112に広がる一方、平均は約0.965、既知の生成関数の値は約0.949と見せる。なぜ近づいたのか、そして5分の1を期待してよいのかを予想させる。

1つの訓練集合から重複を許して標本を引き直し、5つのブートストラップ集合を作る。各集合で同じ種類の多項式回帰を学習し、曲線のずれを同じ軸上で比べる。1点の成功から入力全体の二乗誤差へ進み、モデル間の誤差の違いが平均化で消える様子を面積と棒で見せる。互いに無相関なら $E_{\rm COM}=E_{\rm AV}/M$ となる条件を、共通のずれを持つ場合の実験で崩す。最後に同じ $x=0.45$ の5本と平均へ戻り、「改善したが5分の1とは限らない」という問いに答える。次節の逐次的な重み付けへ問いを渡す。

式だけの画面を続けず、すべての式を曲線、予測点、誤差棒と一緒に置く。軸に装飾枠を置かない。色は入力・元の量を青、平均・結果を緑、演算を黄、比較を紫、誤差を赤に統一する。

## 数値例と近似の条件

説明用の自作データ。生成関数は $h(x)=\sin(2.2x)+0.25x$、入力は区間 $[-1,1]$ の12点、観測ノイズは NumPy RNG seed 3 の正規乱数（標準偏差0.18）。NumPy RNG seed 203で復元抽出した5つの12点集合を使い、5次のLegendre多項式と固定した二次正則化で学習する。冒頭の $x=0.45$ における生成関数の値は約0.948526、5予測の平均は約0.965409。全入力の平均二乗誤差は区間上の一様な501点格子で近似して数値検証する。生成関数は動画の答え合わせ用に既知とする。実問題で未知の真値を使って学習するわけではない。無相関の実験は別の説明用の誤差関数として明示し、ブートストラップの5本が無相関だとは仮定しない。

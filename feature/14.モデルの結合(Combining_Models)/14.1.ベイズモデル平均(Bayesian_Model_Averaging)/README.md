## 物語の設計

13章では1つのモデルの内部で、観測に応じて隠れた状態を推定した。14章は、複数のモデルをどう使うかを問う。全編の問いは「赤3個・青1個を見た後、次が赤になる確率は、なぜ50%にも約76.5%にもなるのか」。冒頭で同じ2枚の確率カード（赤が出る確率80%と20%）と同じ4個の観測から異なる予測を見せ、どちらの計算も正しいと告げる。

まず各個体が独立にカードを選ぶ場合を実験する。選択を表す潜在変数 $z_n$ を毎回置き、選択を見なくても赤の確率が50%となることを図で確かめる。次に、箱全体を1枚のカードで作ったという仮定に替える。観測4個の尤度を計算し、1枚のカードを表す $h$ の事後確率が16/17対1/17へ動く。次の赤の予測が13/17（約76.5%）となり、冒頭の食い違いが解ける。最後は同じ4個と2枚のカードを残し、違いは「選択をいつ行うか」だったと示す。次節のコミッティの予測平均を問いとして渡す。

9シーン、実測8分26秒。図の主役は同じ4個の赤青の観測と2枚のカード。式は図の近くに短く置き、カードの選択、尤度の積、事後の重みを動かす。説明だけの画面を続けない。装飾枠をグラフや軸の背面に置かない。

## 視覚補足と章をまたぐ復習

シーン2では9.2の混合ガウスの「点ごとに成分を選ぶ」図を9.267秒の復習カードRとして再現し、潜在変数 $z_n$ と観測 $x_n$ を対応させる。シーン6では1.2のBayes更新を9.667秒で復習し、事前×尤度→事後の棒を動かす。シーン3には和による周辺化を17.333秒、シーン4には積と和の順番を17.333秒の視覚補足として入れる。合計53.600秒で実測尺の10.6%。同じ章の節は復習しない。入力と観測は青、注目演算は黄、結果は緑、事前と比較は紫、相違は赤を使う。

## 原文との照合

[日本語版PRMLの公開目次](https://ibisforest.org/index.php?openfile=prml-jp-content.pdf&plugin=attach&refer=PRML)による節見出しは「ベイズモデル平均化」、章見出しは「モデルの結合」、次節は「コミッティ」。指定されたディレクトリ名は「ベイズモデル平均」のまま、動画内では原典訳語を示す。

Bishop (2006), *Pattern Recognition and Machine Learning*, §14.1、印刷pp.654–655（PDF pp.674–675）を全文抽出し、両ページを画像で確認した。節内に図はなく、式(14.2)–(14.6)を扱う。章導入の(14.1)は次節以降への接続として言及する。原典のガウス混合とガウス対コーシーのモデル候補はシーン8で扱う。ガウス分布・コーシー分布の詳細な導出は、この節の差異を理解するために不要なので省く。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)を確認し、印刷pp.654–655と式(14.2)–(14.6)の訂正項目はない。

## 数値例と近似の条件

説明用の離散例である。観測順は赤・赤・赤・青。候補Aは各個体が赤である確率0.8、候補Bは0.2。モデルの結合では各個体の成分を独立に確率0.5ずつ選ぶ。したがって各個体の赤は0.5、4個の順序付き列の確率は0.5^4=0.0625。ベイズモデル平均化ではデータ集合全体についてA/Bのどちらかを事前確率0.5ずつで1度だけ選び、各モデルの下では条件付き独立な4個を生成する。順序付き列の尤度はAが0.8^3×0.2=0.1024、Bが0.2^3×0.8=0.0064。事後は16/17と1/17、予測の赤は(16/17)×0.8+(1/17)×0.2=13/17=約0.7647。順序を捨てた「赤3個」の確率は組合せ係数4が別に掛かるが、モデル間の事後比は同じ。映像の計算は順序付きの4個で行う。いずれの確率もこの仮定に条件づけられ、実在する箱の真の製造過程を示すものではない。シーン8のガウス混合は平均±1.5、標準偏差0.62、混合係数0.5ずつの模式図。コーシー混合は同じ中心と混合係数、尺度0.8で描く。両曲線は赤青4個の離散例の尤度ではなく、原典の連続分布の選択単位を見せる別の説明用例である。

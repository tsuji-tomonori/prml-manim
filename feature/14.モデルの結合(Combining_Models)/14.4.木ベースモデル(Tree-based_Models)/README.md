# PRML 14.4 木ベースモデル

Manim と VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）による日本語動画を制作する。

## 物語の設計

14.3 では複数の単純なしきい値を投票で組み合わせた。今回は「同じ入力空間を、1本の木が場所ごとに分けたら、右上の高い1点を信じるべきか」を問う。説明用の 4×4 の観測点では、$x_1$（位置）と $x_2$（高さ）から連続値 $t$ を予測する。右上の1点だけ $t=14$、同じ右半分の他の7点は $t=8$。冒頭では $x=(3.5,3.5)$ の未知の次回観測 $t=8$ を伏せ、大きく育てた木が 14 と予測する意外な結果を見せる。視聴者に「枝を増やしたのに、なぜ外れた？」と予想させる。

全編で同じ 4×4 の点と同じ未知点を保つ。最初の縦分割が右と左を分け、左の横分割が別の平均を作る。葉の値は局所平均になることを短い視覚補足で示す。残差二乗和を比較して分割を1本ずつ増やし、右上の1点を完全に記憶した木を作る。枝刈りでは、葉の数への罰則を加えると右上の枝が消える過程を1つの図のつまみで見せる。結末に同じ未知点へ戻り、枝刈り後の予測 $8.75$ と真値8の差を確かめる。14.5 へは、硬い分割の境目を滑らかにできるかという問いを渡す。

入力を青 `#58C4DD`、操作を黄 `#FFFF00`、結果を緑 `#83C167`、比較を紫 `#9A72AC`、誤りを赤 `#FC6255` でそろえる。グラフに装飾枠・台・影は置かない。数値はアラビア数字、画面注記は日本語にする。

## 視覚補足と章をまたぐ復習

シーン4に二乗誤差と平均の視覚補足（約15秒）を置き、点から予測線までの縦の距離を二乗の面積へ対応させる。シーン6に「1.1 正則化」の復習カード（約12秒）を置き、誤差と複雑さの釣り合いを葉数へ接続する。シーン7に「1.6 交差エントロピー」の復習カード（約12秒）を置く。いずれも本文の図を残し、必要な図形だけ再現する。同章の14.3は冒頭で一言つなぐ。補足と復習は本編の15%以内とする。

## 原文との照合

Bishop (2006) §14.4、印刷 pp.663–666、PDF pp.683–686を `pdftotext -layout` で通読し、図14.5・14.6と式(14.29)–(14.33)を画像で確認した。図は新しい説明例で再制作する。[公式正誤表（2011-09-21）](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)の p.663 図14.5と14.6の併記、p.666 交差エントロピーの負号、純粋な葉と最大値の条件を反映する。CARTの貪欲な分割、葉の平均、枝刈りと交差検証、分類の不純度を扱う。木構造の組合せ最適化の証明、ID3・C4.5 の比較、斜め境界を作る別手法の詳細は扱わない。

## 数値例と近似の条件

4×4 格子で各軸の座標は 0.5、1.5、2.5、3.5。左下4点は $t=2$、左上4点は $t=6$、右半分8点のうち右上端 (3.5,3.5) の1点だけ $t=14$、残り7点は $t=8$。この高い値を説明用の外れ値とする。未知の次回観測は同じ入力 (3.5,3.5) で $t=8$ とする。入力は訓練点と同じでも観測時刻が異なる想定であり、予測値8の保証ではない。貪欲分割は全軸の隣接座標中点を候補とし、残差二乗和の減少が最大の分割を選ぶ。最大木の右上枝を落とす例では $\lambda=18$ とし、枝刈り費用は残差二乗和 $+\lambda|T|$。3葉の費用は $31.5+54=85.5$、5葉の費用は $0+90=90$。右半分の平均は $8.75$、次回観測との差は $0.75$。$\lambda$ は本来交差検証で選ぶが、この動画の18は構造を見せる説明用の値であり、性能最適値とは主張しない。

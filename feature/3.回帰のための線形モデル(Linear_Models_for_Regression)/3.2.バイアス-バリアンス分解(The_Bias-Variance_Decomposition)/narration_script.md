## scene01 同じ方法なのに、予測が変わる？
原文参照: pp.147–148 / Eq.(3.38)

- 青い点から、赤い曲線を学習しました。 この曲線は、次に集めるデータでも同じ形になるでしょうか。
- 同じ条件で、もう一度データを集めてみます。 点を取り替えると、学習した曲線も変わりました。
- ここで変えたのは、訓練データだけです。 学習の方法も、一組に含まれる点の数もそろえています。
- では、曲線をあまり曲がれなくするとどうでしょう。 データを取り替えても、形はあまり変わらなくなります。
- でも、緑の本当の波からは離れています。 安定しているだけでは、よい予測とは言えないのです。
- この動画では、予測のずれを二つに分けます。 平均のずれと、データによる揺れを、順番に見ていきましょう。

## scene02 観測の真ん中を狙う
原文参照: p.148 / Eqs.(3.36)–(3.37)

- まず、横軸の$x$を一つに固定します。 縦軸の$t$は、その入力で観測される値です。
- 同じ入力でも、観測を繰り返すと点は上下に散らばります。 今回は、波に平均ゼロのランダムなノイズを加えた、自作データです。
- 予測の高さを、上から下へ動かします。 観測との距離を二乗した面積の平均は、どこで小さくなるでしょう。
- 観測の平均に合わせると、この二乗の平均が最小になります。 分布が分かる理想的な場合、この高さが条件付き平均です。
- 入力ごとの条件付き平均を結んだ関数が、$h(x)$です。 この実験では、緑の波がその関数に当たります。
- 予測を緑の線に合わせても、灰色の散らばりは残ります。 これが、観測そのものに含まれるノイズです。
- 期待損失は、新しい観測に対する二乗のずれを平均した量です。 式の第一項は、予測と緑の線のずれ。第二項は、残るノイズです。
- ここでの二乗損失は、予測を評価する物差しです。 学習に正則化やベイズ法を使っても、この物差しで評価できます。

## scene03 データを百回取り直したら
原文参照: pp.148–151 / Fig.3.5 / Eq.(3.45)

- 今度は入力全体へ戻り、学習を繰り返します。 一組は二十五点。同じ分布から独立に、百組を作りました。
- 一組目で学習すると、この赤い線になります。 二組目では、点の場所もノイズも違うので、線も変わります。
- 三組目、四組目と、同じ手順で学習していきます。 薄く残した線は、それぞれ別のデータから得た予測です。
- この実験では、二十四個のガウス型の山と定数を材料にします。 その混ぜ方を二十五個の係数で決めます。
- 黄色い線は、百本の予測の平均です。 各入力で百個の高さを足し、百で割って結んでいます。
- 式の$\bar y(x)$が、この有限個の平均です。 理論では、ありうる訓練データ全体について期待値を取ります。
- 期待値は、起こりやすさを重みにした平均のことです。 ここで平均する相手は、入力や観測ではなく、訓練データの組です。
- 一本だけの予測を見ると、うまくいったか偶然かは分かりません。 何度も学び直すことで、その方法のずれ方と揺れ方が見えてきます。

## scene04 ずれを、二つの距離に分ける
原文参照: p.149 / Eq.(3.40)

- 再び、入力を一つに固定しましょう。 百本の曲線との交点を、一本の数直線へ移して眺めます。
- 赤い点が、それぞれの学習で得た予測です。 黄色は予測の平均、緑は本当の条件付き平均です。
- 黄色から緑までの距離が、平均予測のずれです。 これをバイアスと呼び、その二乗を青い正方形の面積で表します。
- 赤い点から黄色までの距離は、学習ごとの揺れです。 それぞれを二乗し、平均した量が、分散、つまりバリアンスです。
- 紫の正方形は、赤い点と黄色い点の距離を二乗したものです。 面積が大きいほど、その回の予測は平均から遠く離れています。
- 点の群れをまとめて動かすと、青い面積だけが変わります。 散らばり方を保ったまま、平均のずれを変えているからです。
- 今度は平均を固定して、点の群れを広げてみます。 紫の面積が増えても、青い面積は変わりません。
- この二つは、異なる種類の失敗を測っています。 ここまでの点の移動は、その違いを分離して見るための模式実験です。

## scene05 平均を足して引くと、式も分かれる
原文参照: pp.148–149 / Eqs.(3.38)–(3.40)

- なぜ二つの量を足せるのか、式で確かめましょう。 ここでは入力を固定し、予測の平均を短く$m$と書きます。
- 予測から本当の平均までの差に、予測の平均を足して引きます。 紫の差と青い差をつなぐと、もとの差に戻ります。
- 和を二乗すると、二つの二乗と、二倍の積に分かれます。 この最後の積が、交差項です。
- 個々の学習結果では、交差項はゼロとは限りません。 予測が平均より上なら正、下なら負になる部分があります。
- しかし、平均からの符号付きの差を全部足すと、打ち消し合います。 平均の定義から、紫の差の期待値はゼロです。
- 青い差は、どの訓練データを取ったかには依存しません。 そのため交差項の期待値は、青い差にゼロを掛けたものになります。
- 残るのは、青い差の二乗と、紫の差の二乗の平均です。 これが、一つの入力でのバイアスとバリアンスの分解です。
- 百本を使う数値実験でも、同じ恒等式が成立します。 分散は百で割ります。不偏分散で使う九十九ではないことに注意しましょう。

## scene06 正則化のつまみで、全体を動かす
原文参照: pp.147,149–152 / Fig.3.5 / Eq.(3.27)（前節）

- ここからは、実際に学習した曲線へ戻ります。 二乗誤差に、係数の二乗を抑える項を足して学習します。
- その強さを決めるのが、$\lambda$です。 つまみは、その自然対数を表示しています。右へ動かすほど正則化が強まります。
- つまみを右へ動かしてみましょう。 係数が小さくなり、赤い曲線の群れは、似た形に集まっていきます。
- 紫の分散は小さくなりました。 一方、黄色い平均が緑の波から離れ、青いバイアス二乗が増えています。
- 今度は、つまみを左へ動かします。 曲線は細かく曲がれるようになり、それぞれのデータに合わせて形を変えます。
- 黄色い平均は緑へ近づきました。 でも一本ずつの赤い線を見ると、平均の周囲で大きく揺れています。
- 最後に、中ほどの強さへ戻します。 この例では、平均のずれと揺れの両方を、ほどよく抑えられます。
- 学習の誤差関数を、そのまま正則化の強さについても最小化するとどうなるでしょう。 非負の追加項を消せる、強さゼロが選ばれます。これでは強さを選ぶ基準になりません。

## scene07 入力全体で足すと、予測誤差になる
原文参照: pp.149–151 / Eqs.(3.41)–(3.47) / Fig.3.6

- 一つの入力で分けた量を、今度は入力全体で平均します。 積分は、入力の起こりやすさを重みにして、細かく足し合わせる記号です。
- 青はバイアス二乗、紫は分散、灰色はノイズです。 期待損失は、この三つの合計になります。
- 数値計算では、独立に引いた入力の点で積分を近似します。 本当の関数と平均予測のずれを二乗して平均すれば、青い量が求まります。
- 各予測から平均予測へのずれも、二乗して平均します。 訓練データの組についてと、入力について、二段階で平均するのです。
- 横軸を正則化の強さにして、計算した量を描きましょう。 右へ進むと、青が上がり、紫が下がる様子が見えます。
- 黄色は青と紫の合計です。 いちばん低い位置が、この数値実験での、よい釣り合いです。
- 白い線は、合計にノイズを足した理論上の期待損失です。 灰色の点は、独立なテストデータで測った誤差。有限個なので少しずれます。
- この実験のノイズ分散は、$0.0625$です。 つまみを変えても、この土台は残ります。最適な強さの数値は、データやモデルで変わります。

## scene08 この平均は、実際に計算できる？
原文参照: pp.151–152 / §3.3 への接続

- ここまで、百組の独立な訓練データを用意してきました。 実際の問題で手元にあるのは、多くの場合、一組だけです。
- 本当の条件付き平均も、普通は分かりません。 そのため、この分解だけで、実データの最適な強さを直接決めることはできません。
- 独立な訓練データが本当にたくさんあるなら、一つに集めて学習に使えます。 より多くの観測を使うことで、予測を安定させる助けになります。
- 一方、曲線を平均するという発想は、次の節へつながります。 ベイズ法では、一組のデータをもとに、係数の事後分布を考えます。
- 事後分布は、データを見た後で、どの係数がどれくらいありそうかを表します。 そこで平均する相手は、データの組ではなく、係数の候補です。
- 予測を選ぶときは、平均のずれと、学び直したときの揺れを考える。 さらに観測のノイズを分ける。この三つが、バイアスとバリアンス分解の見取り図です。

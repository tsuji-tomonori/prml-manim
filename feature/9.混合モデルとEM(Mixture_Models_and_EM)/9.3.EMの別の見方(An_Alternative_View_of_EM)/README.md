# PRML 9.3 EMの別の見方

Manim と VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）の日本語動画。全8シーン、約8分16秒。9.2 の同じ16点の説明用データを引き継ぐ。

## 物語の設計

全編の問いは「$x=0.15$ を作った成分の札は見えないのに、9.2のEMはなぜ山を更新できたのか」。冒頭では9.2と同じ初期の2つの山を残し、距離では青が近い点を赤が0.564だけ引き受ける意外な色をもう一度示す。もし赤か青の札が見えれば、山ごとの計算は簡単になる。しかし札は観測されない。その欠落をどう扱うかを各場面の実験で追う。

| シーン | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 見えない札で山を動かす？ | 9.2と同じ点・山・負担率を示し、「札なしで更新できた理由」を問う |
| 2 札があれば簡単？ | 観測データの「対数の中に成分の和」と、札付きの分けられる式を、同じ点図に重ねて比べる |
| 3 札を推測して平均する | 赤と青の候補札を負担率で重ね、期待値の短い図解から $Q(\theta,\theta^{old})$ を作る |
| 4 重みを固定して山を動かす | Eで得た重みを凍結し、Mで平均・幅・混合係数を更新する。9.2と同じ1回目の値になる |
| 5 もう一度札を推測すると？ | 山が動いた後の負担率を再計算し、対数尤度の上昇を追う。上昇の厳密な理由は9.4へつなぐ |
| 6 幅を絞るとK平均に？ | 共通の分散を小さくし、柔らかい負担率が最近中心への硬い割当てへ近づくのを、同じ軸で見る |
| 7 山でなく0/1の模様なら？ | 2.1のベルヌーイ分布を短く復習し、4画素の説明用模様で同じE/Mの構造を示す |
| 8 最初の札へ戻る | 同じ$x=0.15$、同じ初期値へ戻り、赤0.564の札の期待値が重みになることを確認する |

視覚補足は「期待値＝確率で重み付けした平均」を8.8秒、章またぎ復習は「2.1 ベルヌーイ分布」を12.5秒置く。本文の説明と同時に動かし、合計21.3秒（全編の4.3%）。9.1、9.2は同じ章なのでカードを増やさず一言でつなぐ。入力=青`#58C4DD`、演算=黄`#FFFF00`、結果=緑`#83C167`、比較=紫`#9A72AC`、誤差=赤`#FC6255`。成分は9.2と同じ赤・青。図の背面に装飾の枠・台・影を置かない。

## 視覚補足と章をまたぐ復習

- 3場面の期待値は、2枚の札へ0.564/0.436を載せ、確率で重み付けした和を図にしてから$Q$へつなぐ。8.8秒。
- 7場面の復習カードは「復習: 2.1 ベルヌーイ分布」を左上に白字・細い黄枠で表示。0/1の棒と確率の一操作のみを元節から再現する。12.5秒。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §9.3–9.3.4、印刷pp.439–450（PDF pp.459–470）の全文を確認した。図9.9（印刷p.442）と図9.10（印刷p.448）をPDF画像で確認した。中心は式(9.29)–(9.43)、ベルヌーイ混合の式(9.44)–(9.60)。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)では(9.39)、(9.41)、(9.56)などを訂正する。(9.41)の一般の$D$次元の正規化定数は$(2\pi\epsilon)^{D/2}$。本編は1次元で描く。式(9.40)の負担率は9.2と同じ日本語版訳語「負担率」とする。9.3.4のベイズ線形回帰、RVM、MAP拡張、欠測機構の条件、図9.10の手書き数字600枚は中心の問いから外れるため、構造の一般性を4画素のベルヌーイ混合で代表して短く扱う。原典図は複製しない。

## 数値例と近似の条件

- 9.2と同じ固定16点、$\mu=(-1.1,1.1)$、$\sigma=(0.9,1.2)$、$\pi=(0.65,0.35)$。$x=0.15$の赤い負担率は約0.563550、青は約0.436450。1回のEM更新は赤の中心−0.943940、混合係数0.545252となり9.2の計算と一致する。固定した古い負担率で$Q$は−32.705515→−31.654827、観測対数尤度は−27.737480→−26.520585。$Q$と観測対数尤度は別の量として表示する。
- K平均への極限は、2成分に共通の分散$\epsilon>0$を固定し、混合係数を正に保つ。中心からの距離が等しくない点で$\epsilon\to0$とし、数値的には有限の正の値で近づく様子を描く。分散を再推定する通常のガウス混合EMの履歴とは別の実験。
- ベルヌーイ混合は4画素の固定した説明用0/1模様を使う。各画素は成分を条件に独立で、確率は0より大きく1より小さい。原典の手書き数字データではない。

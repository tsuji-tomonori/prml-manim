# PRML 9.4 一般的なEMアルゴリズム

Manim と VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）の日本語動画。9.3 の16点と初期混合モデルを引き継ぐ。

## 物語の設計

全編の問いは「札を推測して山を動かすだけで、なぜ観測データの対数尤度は下がらないのか」。冒頭では9.3と同じ16点・初期値を置き、1回のEM更新で対数尤度が−27.737から−26.521へ上がる様子を見せる。ただし点の成分札は見えない。見えない札をいったん確率で置いたとき、なぜ観測データの採点まで改善するのかを問う。

| シーン | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 上がったのは偶然？ | 同じ16点で実測の尤度を示し、9.3から保証の問いを引き継ぐ |
| 2 採点を2つに分ける | 任意の札の分布 $q(Z)$ を置き、対数尤度を下界 $\mathcal L(q,\theta)$ と KL の差に分ける |
| 3 下界はなぜ下にある？ | KLを「札の分布のずれ」として短く図解し、非負性から下界を示す |
| 4 Eで何がそろう？ | 今のパラメータで事後分布を計算し、KLが0となって下界が観測対数尤度に接する |
| 5 Mで何を動かす？ | $q$を固定して完全データの期待対数尤度 $Q$ を上げる。下界の増分と尤度の増分を同じ高さ図で比較する |
| 6 交互の軌跡 | 16点を使った実際の1回の数値を、同じパラメータ空間と高さ図に戻して照合する |
| 7 どこまで一般化できる？ | 事前分布を加えたMAP、下界を増すだけの一般化EMを、同じ図の操作として短く示す |
| 8 冒頭の16点へ戻る | 同じ初期値・同じ更新で、下界とKLの値を使い「下がらない」の理由を確認する |

9.3は同じ章の直前なので独立した復習カードを重ねない。章またぎの復習は1.6「KLダイバージェンス」を使う直前に、青と紫の2本の確率棒で12秒程度。補足は期待値を使う直前に「札ごとの値を確率で重み付けする」小窓を10秒程度。合計は本編の15%以内とする。入力と元の量は青、注目する操作は黄、結果は緑、比較は紫、差は赤。9.3の混合成分は赤・青を保つ。図の背面に装飾枠は置かない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §9.4、印刷pp.450–455（PDF pp.470–475）の全文を確認。図9.11–9.14をPDF画像で確認する。中心は式(9.69)–(9.77)。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)のp.452は(9.74)直後の「negative」を削除、p.453は下界の記号を$\mathcal L(q,\theta^{old})$に訂正し、曲線をconvexでなくconcaveと訂正する。本編ではこの誤記を引き継がない。式(9.78)–(9.79)の逐次更新と部分Eの収束条件は、中心の保証から外れるため詳細な導出を省く。

## 数値例と近似の条件

- 9.3と同じ固定16点、$\mu=(-1.1,1.1)$、$\sigma=(0.9,1.2)$、$\pi=(0.65,0.35)$を使う。$x=0.15$の赤い負担率は0.563550。
- Eで得た全16点の$q$を固定した1回のM更新後、観測対数尤度は−27.737480→−26.520585。$Q$は−32.705515→−31.654827。$q$のエントロピーは4.968035で固定され、下界は−27.737480→−26.686791。新しいKLは0.166207。数値は実コードで再検算する。
- 高さ図は上記の離散混合モデルの値から作る。パラメータ空間の1次元断面を示す場合は、どのパラメータを固定したかを画面とREADMEに明記する。

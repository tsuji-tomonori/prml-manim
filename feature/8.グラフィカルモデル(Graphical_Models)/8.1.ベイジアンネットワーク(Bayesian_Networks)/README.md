# PRML 8.1 ベイジアンネットワーク

## 物語の設計

全編の問いは「ぬれた道を見たとき、その日に傘を持つ人の確率をどう求めるか」。冒頭で雨の日に傘を持つ確率 0.8 を示し、道がぬれていれば同じ 0.8 と予想させる。実際には、雨が降らずに道がぬれる日もある。雨という見えない変数を含む図でこの違和感を解き、同じ確率表で計算した答え 0.676 を最後に回収する。

7.2 までの関数や重みの予測を、8章では確率変数間の依存を図で設計する問いへ引き継ぐ。矢印があることより、不要な矢印を外したときに何を仮定するかを主題にする。雨・道・傘の3変数を同じ図上で変形し、積の規則、親ごとの条件付き分布、観測による更新、祖先サンプリングへ順に進む。その後、原典の多項式回帰、離散変数、線形ガウスの例で図法を一般化し、冒頭の3変数へ戻る。

物語上の自作モデルでは $R$=雨、$D$=ぬれた道、$U$=傘。$p(R=1)=0.3$, $p(D=1\mid R=1)=0.9$, $p(D=1\mid R=0)=0.1$, $p(U=1\mid R=1)=0.8$, $p(U=1\mid R=0)=0.2$ とする。$D$ と $U$ が $R$ の下で独立という**このモデルの仮定**を明示し、矢印を普遍的な因果証明とは扱わない。

## 数値例と近似の条件

- 雨・道・傘は説明用の自作二値モデルで、原典の数値例ではない。$D\perp U\mid R$ はこのモデルの条件付き分布を定義する仮定。
- $p(D=1)=0.3\cdot0.9+0.7\cdot0.1=0.34$。$p(R=1\mid D=1)=0.27/0.34=0.7941176$。$p(U=1\mid D=1)=(0.27\cdot0.8+0.07\cdot0.2)/0.34=0.6764706$。$p(U=1\mid R=1)=0.8$ とは条件が違う。
- 祖先サンプリングを示す標本は固定 seed の乱数から自作し、実測値として表示する。標本頻度と理論確率を区別する。
- 4個の二値変数のパラメータ数は、一般の同時分布15、鎖 $1+3\cdot2=7$、独立4。矢印の省略は表現可能な分布の制限と引き換えになる。
- ガウス鎖は $x_1\sim N(0,1)$、$x_2\mid x_1\sim N(0.8x_1,0.36)$、$x_3\mid x_2\sim N(0.6x_2,0.25)$ の自作例。線形な親の平均と独立なガウス雑音という条件の下で、同時分布もガウスになる。

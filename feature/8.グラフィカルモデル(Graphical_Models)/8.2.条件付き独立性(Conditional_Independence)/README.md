# PRML 8.2 条件付き独立性

Manim と VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速 1.08、抑揚 1.08）で制作する日本語動画。

## 物語の設計

全編の問いは「燃料計の空表示で燃料切れが約 0.257 へ上がったのに、バッテリー切れを知ると約 0.111 へ下がるのはなぜか」。原典図 8.21 の電池 $B$、燃料 $F$、燃料計 $G$ を使う。冒頭で空表示を見せ、燃料切れがより濃厚になると予想させる。その後に電池切れを示し、逆向きの確率変化を図と棒で見せる。

8.1 で雨を介して道と傘を結んだ図を、条件付き独立を読む出発点とする。まず「共通の親」「鎖」は中間を知ると経路が閉じることを示す。次に「2 本の矢印が合流する子」は未観測なら閉じ、子やその子孫を観測すると開くことを、同じ燃料計で発見する。複数経路の d 分離を確認し、条件付きの独立という仮定がデータをどれだけ単純化するかを見せる。最後に冒頭と同じ $B,F,G$ と数値へ戻る。

原典の確率表をそのまま使う。$p(B=1)=p(F=1)=0.9$。$p(G=1\mid B,F)$ は $(B,F)=(1,1),(1,0),(0,1),(0,0)$ の順に $0.8,0.2,0.2,0.1$。1 は充電・燃料あり・満表示。0 は電池切れ・燃料切れ・空表示。$B$ と $F$ は事前に独立である。この表から $p(G=0)=0.315$、$p(F=0\mid G=0)=0.081/0.315\simeq0.257$、$p(F=0\mid G=0,B=0)=0.09/0.81\simeq0.111$。

- scene06 に総和の短い補足を約 12 秒。4 状態を足して $p(G=0)$ を作る。
- 補足・復習は本編の 15% 以内に収める。青は元の量、黄は観測・演算、緑は結果、紫は比較、赤は減少・遮断。枠は補足の内容を区別する場合だけ使用し、グラフ背面には置かない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §8.2、印刷 pp.372–383（PDF pp.392–403）を `pdftotext -layout` で全文確認。図 8.15–8.26 を PDF 画像でも確認する。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf) では p.376 の条件付き積、p.378 の子孫に関する文、p.380 の積分下限を訂正として確認した。動画は正しい条件付き積 $p(a\mid c)p(b\mid c)$ に従う。

本編では d 分離の形式的証明、パラメータ節点の特殊扱い、多項式回帰の独立性 (8.36)、ナイーブベイズのガウス推定・決定境界の詳細、分布族をフィルタとして見る図 8.25 の厳密な同値性は扱わない。結末ではマルコフブランケットの親・子・共同の親を、次のグラフ読解への短い橋として示す。

## 数値例と近似の条件

- 燃料計の確率表は原典の値。確率の内部計算は厳密な 10 進数相当の有理数または浮動小数で行い、画面の 0.257 と 0.111 は小数第 3 位への丸め。0.111 は事前の 0.1 よりまだ大きい。
- 8.1 の雨・道・傘は復習元の自作二値モデルを再現する。雨を固定した下で道と傘は独立というモデルの仮定であり、矢印自体は現実の因果の証明ではない。
- d 分離は図に従うすべての分布で成り立つ独立性を判定する。数値の偶然で追加の独立性が生じても、図が保証する性質とは区別する。
- scene02 の 4 本の短い棒は説明用の条件付き確率 $p(a=1\mid b,c)$。$c=0$ の行で $(b=0,b=1)=(0.3,0.3)$、$c=1$ の行で $(0.8,0.8)$ とする。$p(b,c)$ は指定せず、条件を固定して比較する目的にだけ使う。
- scene04 の鎖の両端の棒 0.62 は説明用の $p(b=1\mid c=1)$ を両方の $a$ へ同じ長さで描いたもの。数値検証では $p(a=1)=0.5$, $p(c=1\mid a=1)=0.8$, $p(c=1\mid a=0)=0.2$, $p(b=1\mid c=1)=0.62$, $p(b=1\mid c=0)=0.15$ を使う。全同時分布の推定値とは扱わない。
- 子孫の効果の数値検証には、$a,b\sim\mathrm{Bernoulli}(0.5)$ を独立とし、合流点 $e=a\lor b$、子 $c$ の確率を $p(c=1\mid e=1)=0.9$, $p(c=1\mid e=0)=0.1$ とした説明用モデルを使う。映像ではこの数値を出さず、経路の開閉だけを見る。
- scene06 の電池切れを固定した 2 本の 0.09 と 0.72 は、それぞれ $p(G=0\mid B=0,F=0)p(F=0)$ と $p(G=0\mid B=0,F=1)p(F=1)$。共通の $p(B=0)$ が条件付き確率の比で相殺される。scene07 は原典図 8.22 の $a\to e\leftarrow f\to b$, $e\to c$ に説明用の第 2 経路 $a\to h\to b$ を追加し、「全経路が閉じる」の条件を見せる。

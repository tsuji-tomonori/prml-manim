# PRML 8.3 マルコフ確率場

Manim と VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速 1.08、抑揚 1.08）による日本語動画を制作する。

## 物語の設計

全編の問いは「ノイズで白くなった黒い画素を、周りの画素だけを手がかりに戻せるのはなぜか」。説明用の 12×12 の二値画像で、黒い図形の内側の 1 画素を反転させる。冒頭では観測値を信じて白のままにするか、周囲に合わせて黒へ戻すかを予想させる。8.2 の矢印付きグラフでは合流点の観測が経路を開いたことに短く触れ、矢印を外した図なら「近所だけ」がどこまで保証されるかを追う。

無向グラフの経路を遮る条件、隣接点だけのマルコフブランケット、最大クリーク上のポテンシャル、全体を確率にする分配関数を、画像の 1 画素の問いへ順に戻して確かめる。観測画像と隣接画素の双方に従うエネルギーを使い、同じ画素で 2 候補の値を比較する。局所更新を画像全体に広げ、反転前の画像との一致率で結果を検証する。最後は冒頭と同じ座標・同じ画像を見せる。8.4 に向けて、局所更新が止まっても全体の最良解とは限らないという問いを残す。

## 視覚補足と章をまたぐ復習

- scene02 冒頭に、8.2 の燃料計の合流点を一言でつなぐ。同じ章なので復習カードは作らない。
- scene04 で 1.2 の「正の重みを合計で割って確率にする」図を、節番号付きの復習カード R として短く再現する。scene07 の分配関数を読む準備にする。
- scene04 で最大クリークを、3 点の完全結合と欠けた辺のある 4 点から選ぶ短い視覚補足にする。
- scene04 で局所の重みの積から `exp(-E)` へ対応させ、scene05 の 2 候補のエネルギー棒へつなぐ。補足と復習は本編の 15% 以内にする。
- 青は観測・元の値、黄は比較する操作、緑は選ばれた結果、紫は近所、赤は誤り。装飾枠や台をグラフ背面に置かない。復習カードの細い枠だけを使う。

復習カード R は scene04 の 9.13 秒。最大クリークの図解 17.47 秒と指数の補足 9.07 秒まで独立補足として数えても合計 35.67 秒、全編の実測音声 518.93 秒の 6.87% に収まる。scene05 の局所エネルギーは本文の実験そのものとして数え、補足を重ねない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §8.3、印刷 pp.383–393（PDF pp.403–413）を `pdftotext -layout` で全文確認。図 8.27–8.36 は PDF の画像を確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)の該当箇所は、p.390 の図 8.32(b) の右端 2 節点のラベル入れ替えと、同ページの `max-product` を `max-sum` に直す指示。動画では図の順序を正しく描き、次節への予告はアルゴリズム名を断定しない。

本編は画像復元を軸に選ぶ。Hammersley–Clifford 定理の証明、連続変数への積分拡張、道徳化の厳密な構成証明、完全写像の全分類、グラフカットのアルゴリズム詳細は扱わない。正のポテンシャルを前提にすると、分離と因子分解が対応することだけ述べる。

## 数値例と近似の条件

- 映像の二値画像は本動画用の自作データ。画素は黒 $-1$、白 $+1$、上下左右の 4 近傍で結ぶ。$12\times12=144$ 画素のうち 14 画素を反転（約 9.72%）。`image_model.py` の `FLIPS` が 0 始まりの行・列を固定する。観測画像は元画像と 130/144 一致する。冒頭で注目する画素は行 5・列 5 の観測値 $+1$ で、上下左右の観測値はすべて $-1$。
- エネルギーは原典 (8.42) の $E(x,y)=h\sum_i x_i-\beta\sum_{\{i,j\}}x_ix_j-\eta\sum_i x_iy_i$ を使う。説明用に $h=0,\beta=1,\eta=2.1$ とする。全てのポテンシャルが正である。局所の 2 候補は他の画素を固定して比較する。ICM は局所解に止まる場合がある。
- 注目画素の局所エネルギーは白 $+1.9$、黒 $-1.9$。1 巡目で 8 画素が変化し、2 巡目で変化 0。復元画像は元画像と 138/144 一致（約 95.83%）。全体エネルギーは $-378.4\to-404.8$。座標・結果・候補差は `verify_numerics.py` で独立に検算する。
- scene07 の 16 本の重み棒は、本編の 12×12 画像とは別の 2×2 の二値モデル。4 本の辺の係数を 0.13、4 個の画素の係数を 0.10 とし、各状態 $s\in\{-1,+1\}^4$ に $\exp[0.13(s_1s_2+s_1s_3+s_2s_4+s_3s_4)+0.10\sum_i s_i]$ を割り当てる。分配関数は $16.9863623824$。棒はこの式から生成する。主例の $\beta,\eta$ と混同しない。
- 原典図 8.30 の 96%・99% は原典の画像と手法の結果であり、この自作画像の結果として表示しない。

## 検証と限界

- `python -W error -m py_compile *.py`、`verify_numerics.py`、`verify_caption_layout.py` を通過。全 126 字幕の最大幅は 9.953、最大高は 0.619。数式入り字幕は 7 文。
- 9 シーン・63 ビート・126 文の manifest、台本、WAV ハッシュと字幕時刻を照合した。`audio_query` で全 126 文の読みを確認し、読みの修正履歴を `reading_check.json` / `.md` に保存した。
- `--disable_caching --flush_cache -ql` で全編を再レンダリングした。`ffprobe` は H.264/AAC、854×480、15 fps、映像 518.929 秒、音声 518.976 秒。`silencedetect` の 3 秒以上の無音は 0 件、`volumedetect` は平均 -26.4 dB・最大 -6.0 dB。全編デコードを通過した。
- MP4 と WAV の 126 文の波形照合は最小相関 0.999480、最大時刻差 0.021333 秒。261 フレームを抽出し、全 63 ビートの中間と、強調・移動・色替えのある 21 ビートの開始・序盤・終盤、計 126 代表フレーム以上を目視した。復習カードの枠と注記、数式字幕、近傍の強調、エネルギー棒、画素の更新、道徳化の線の変化を拡大確認し、意図しない重なりを認めなかった。
- 高解像度版と動画全編の人手による聴取は未実施。指定された 480p15 の映像・音声について検証した。レビュー画像は Git 管理外の `media/review/` に保存する。

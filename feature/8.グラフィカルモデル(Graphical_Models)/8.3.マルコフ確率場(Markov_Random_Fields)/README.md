# PRML 8.3 マルコフ確率場

Manim と VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速 1.08、抑揚 1.08）による日本語動画を制作する。

## 物語の設計

全編の問いは「ノイズで白くなった黒い画素を、周りの画素だけを手がかりに戻せるのはなぜか」。説明用の 12×12 の二値画像で、黒い図形の内側の 1 画素を反転させる。冒頭では観測値を信じて白のままにするか、周囲に合わせて黒へ戻すかを予想させる。8.2 の矢印付きグラフでは合流点の観測が経路を開いたことに短く触れ、矢印を外した図なら「近所だけ」がどこまで保証されるかを追う。

無向グラフの経路を遮る条件、隣接点だけのマルコフブランケット、最大クリーク上のポテンシャル、全体を確率にする分配関数を、画像の 1 画素の問いへ順に戻して確かめる。観測画像と隣接画素の双方に従うエネルギーを使い、同じ画素で 2 候補の値を比較する。局所更新を画像全体に広げ、反転前の画像との一致率で結果を検証する。最後は冒頭と同じ座標・同じ画像を見せる。8.4 に向けて、局所更新が止まっても全体の最良解とは限らないという問いを残す。

| 4 局所の好みを作る | 矢印の条件付き確率の代わりは何か → 最大クリークとポテンシャル → 候補の重み | pp.385–387、図 8.29、(8.39)–(8.41) |

## 視覚補足と章をまたぐ復習

- scene02 冒頭に、8.2 の燃料計の合流点を一言でつなぐ。同じ章なので復習カードは作らない。
- scene04 で 1.2 の「正の重みを合計で割って確率にする」図を、節番号付きの復習カード R として短く再現する。scene07 の分配関数を読む準備にする。
- scene04 で最大クリークを、3 点の完全結合と欠けた辺のある 4 点から選ぶ短い視覚補足にする。
- scene05 で積から和への操作と `exp(-E)` を、重みの棒とエネルギーの高さに対応させる。補足と復習は本編の 15% 以内にする。
- 青は観測・元の値、黄は比較する操作、緑は選ばれた結果、紫は近所、赤は誤り。装飾枠や台をグラフ背面に置かない。復習カードの細い枠だけを使う。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §8.3、印刷 pp.383–393（PDF pp.403–413）を `pdftotext -layout` で全文確認。図 8.27–8.36 は PDF の画像を確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)の該当箇所は、p.390 の図 8.32(b) の右端 2 節点のラベル入れ替えと、同ページの `max-product` を `max-sum` に直す指示。動画では図の順序を正しく描き、次節への予告はアルゴリズム名を断定しない。

本編は画像復元を軸に選ぶ。Hammersley–Clifford 定理の証明、連続変数への積分拡張、道徳化の厳密な構成証明、完全写像の全分類、グラフカットのアルゴリズム詳細は扱わない。正のポテンシャルを前提にすると、分離と因子分解が対応することだけ述べる。

## 数値例と近似の条件

- 映像の二値画像は本動画用の自作データ。画素は $-1,+1$、上下左右の 4 近傍で結ぶ。反転位置、観測画像、ICM の更新順、一致率、冒頭の画素のエネルギーは実装から計算し、完成時にここへ記録する。
- エネルギーは原典 (8.42) の $E(x,y)=h\sum_i x_i-\beta\sum_{\{i,j\}}x_ix_j-\eta\sum_i x_iy_i$ を使う。説明用に $h=0,\beta=1,\eta=2.1$ とする。全てのポテンシャルが正である。局所の 2 候補は他の画素を固定して比較する。ICM は局所解に止まる場合がある。
- 原典図 8.30 の 96%・99% は原典の画像と手法の結果であり、この自作画像の結果として表示しない。

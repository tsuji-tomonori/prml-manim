# PRML 12.1 主成分分析

## 物語の設計

全編の問いは「傾いた13点を1本の線に圧縮するとき、横軸より斜めの線を選ぶ理由は何か」。11章では複雑な分布から標本を作った。12章では多くの観測値を少ない連続潜在変数で表す。説明用の2次元点群を一貫して使い、横軸へ落とす予想から始める。横軸への平均二乗再構成誤差は約1.349、主成分へ落とすと約0.046。角度を動かして「投影後の分散を最大にする」と「直交する残差を最小にする」が同じ線を選ぶことを発見し、最後に同じ13点と値へ戻る。青は元の点、黄は投影・操作、緑は保持、紫は比較、赤は誤差。

| シーン | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 | 多次元観測を1変数へ縮められる？ → 13点を横軸へ投影 → 誤差が大きく、線の向きが問いになる |
| 2 | 何を中心に線を置く？ → 平均を動かし中心を一致させる → 平均を通る線が自然 |
| 3 | 向きをどう選ぶ？ → 角度つまみと影を同じ散布図上で動かす → 影の分散が最大の線を候補にする |
| 4 | 分散の式は図の何を数える？ → 2.3の共分散を復習し、影の二乗を図へ対応 → 単位方向の二次形式になる |
| 5 | 最大の角度はどう見つける？ → 単位円上の方向と分散曲線を連動 → 最大固有値の固有ベクトルを得る |
| 6 | 長い影を残すと誤差はどうなる？ → 同じ角度つまみで直角の残差を測る → 全分散から保持分散を引く |
| 7 | 1本から何本へ増やす？ → 再構成を M=0,1,2 と切り替える → 捨てた固有値の和が平均二乗誤差 |
| 8 | 主成分は何に使える？ → 同じ点群を保存・復元し、白色化を短く見せる → 圧縮と前処理、線形の限界 |
| 9 | 冒頭の横軸でよかった？ → 同じ13点・横軸・斜め線・誤差を再表示 → 斜め線の理由を確認し、12.2の確率的な扱いへ渡す |

## 視覚補足と章をまたぐ復習

- 2.3の共分散・ガウス楕円を使う直前に復習カードRを置く。元図を必要な形だけ再現し、過去節をimportしない。
- 単位方向への投影と分散の二次形式は、元の点・影・二乗した長さを同じ色で対応させる短い補足を入れる。
- 固有ベクトルは、単位円上の方向を動かし、分散の極値を同時に示す。微分とラグランジュ乗数の細かい代数操作は本編に詰め込まない。
- 復習と補足の合計は本編尺の15%以内にする。

## 原文との照合

Bishop (2006) §12.1、印刷pp.561–570（PDF pp.581–590）の全文と図12.2–12.8を参照する。中心は式(12.1)–(12.6)、(12.10)–(12.20)である。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)のp.564・565–567の訂正を確認する。図12.3–12.5は数字の「3」に対象が限られ、図12.3は最初の4固有ベクトル、図12.4・12.5も同じデータである。本編では原典の手書き数字データの値を再現せず、説明用13点で圧縮を示す。CCA、Fisher判別との詳細比較、白色化の式(12.22)–(12.25)、高次元データの双対固有値問題(12.26)–(12.30)は扱わない。

## 数値例と近似の条件

13点の説明用データは `pca_model.py` で固定する。標本共分散はPRMLの式(12.3)と同じ1/Nを使う。線は平均を通し、方向は単位ベクトル。誤差は点から線への直交距離の二乗の標本平均。横軸の誤差は約1.349、第一主成分の誤差は約0.046。個々の点と再構成値は同じデータから計算する。丸め表示は約と明示する。白色化は正の固有値に対してのみ説明する。

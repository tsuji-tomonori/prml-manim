# PRML 12.3 カーネル PCA

## 物語の設計

全編の問いは「対角に並ぶ同じ色の点を、なぜ普通の PCA の 1 軸では分けられず、カーネル PCA の 1 軸では分けられるのか」。12.1 では投影後の分散が最大になる線を選び、12.2 ではその線に沿う確率密度を与えた。本節では線形の投影が拾えない並び方を扱う。説明用の 16 点は、横座標が約 ±1.2、縦座標が約 ±1.0 の 4 群にある。右上と左下を緑、左上と右下を紫で示す。色は検算のための表示であり、PCA の計算に渡さない。冒頭で横軸への投影を予想させると両色が重なる。2 つの座標の積を特徴にした後、同じ 16 点の第 1 主成分得点に戻って分離を確かめる。

| 2 | 色の並びを表す量は？ → 座標の符号を掛け、点を積の軸へ動かす → 対角の 2 群で符号が揃う | 図12.16、特徴写像 |

## 原文との照合

Bishop (2006) §12.3、印刷 pp.586–590（PDF pp.606–610）の全文を `pdftotext -layout` で読み、図12.16・12.17を PDF 画像でも確認した。中心は (12.71)–(12.87)。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf) では p.588 の (12.78) 左辺内側の総和上限を $N$、(12.79) 後の係数を $a_{in}$ とする。映像では修正後の式を用いる。原典の図12.17はガウスカーネルと 3 群の例。本動画の数値例は二次多項式カーネルを用いる自作16点であり、原典の図の数値を再現したものではない。

扱う範囲は、特徴空間の PCA、内積の置換、Gram 行列の中心化、新点への射影、計算量と逆写像の限界。零固有値の係数の非一意性は短く触れ、証明の細部、近似的逆写像の求解法、大規模近似アルゴリズムは扱わない。

## 数値例と近似の条件

4 群の中心は $(\pm1.2,\pm1.0)$。各群に $(\pm0.08,\pm0.05)$ の 4 通りのずれを足し、合計 $N=16$ 点とする。色の組は中心の座標の積の符号で定めるが、固有分解には色を使わない。通常 PCA の共分散は $N$ 分の 1 で計算し、固有値は $1.4464,1.0025$。第 1 軸は $x_1$ 方向で、どちらの色も同じ横座標に現れる。

$\phi(x)=(x_1^2,\sqrt2 x_1x_2,x_2^2)^T$、$k(x,z)=\phi(x)^T\phi(z)=(x^Tz)^2$ とする。特徴空間の中心化後の固有値は $2.900032,0.036864,0.010000$。第 1 主成分は積の成分で、得点はこの対称な例では $y_1(x)=\sqrt2 x_1x_2$。緑の得点は約 $1.505$〜$1.901$、紫は約 $-1.901$〜$-1.505$。中心化前の Gram 行列の最大固有値は約 $50.0044$、中心化後は $46.400512=N\times2.900032$。表示する小数は丸め値。

新点 $x_*=(0.9,0.8)$ の得点は約 $1.018234$。訓練点で決めた特徴平均を使い、新点を加えて平均を再推定しない。元の空間に戻す図では、訓練点 $(1.28,1.05)$ の特徴を第1軸へ射影する。特徴写像の像は $\phi_2^2=2\phi_1\phi_3$ を満たすが、射影点では左辺が約 $3.612672$、右辺が $2.900032$ となり一致しない。すべて説明用の有限データによる結論であり、任意のデータやカーネルで色が分かれるとは主張しない。

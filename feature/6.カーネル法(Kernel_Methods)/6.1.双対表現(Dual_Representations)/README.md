# PRML 6.1 双対表現

## 物語の設計

全編の問いは「3点 $(-1,1),(0,0),(1,1)$ から作る $x=0.5$ の予測 $0.368421$ を、学習済みの重み $w$ を予測時に直接使わず、学習点との比較だけで再現できるか」。5章までの「学習した重みを使う」視点から、6章の「学習点との比較を残す」視点へ移る。冒頭では近い2点の値 $0$ と $1$ の平均 $0.5$ を予想させ、正則化した二次特徴の予測は $0.368421$ と示す。なぜ違い、比較だけで同じ値を出せるのかを追う。

1. **予想と違和感**：$x=0.5$ の隣の2点から $0.5$ を予想する。同じ3点で二次特徴の正則化回帰を行うと $0.368421$。重みを介さずに値を再現できるか。
2. **誤差を小さくする**：3.2の正則化付き最小二乗を節番号付きで復習。$\lambda=0.5$ で残差と重みの大きさを一緒に見る。最適点で勾配が0になる意味を短い図で補う。
3. **重みの出所**：勾配0の式をほどくと、$w$ は訓練点の特徴 $\phi(x_n)$ の重み付き和となる。係数 $a_n$ へ役割を移す。
4. **比較の表**：3.1で使った特徴と内積を短く復習。各点の特徴の対応成分を掛けて足し、カーネル $k(x,x')$ とGram行列 $K$ を組み立てる。
5. **係数を決める**：$a=(K+\lambda I)^{-1}t$。正誤表に従い (6.3) を (6.4) へ代入して導く。逆行列は「この連立方程式を解く」の意味にとどめ、実計算は `solve` を使う。$\lambda$ が対角へ加わる様子を見せる。
6. **冒頭への回帰**：$x=0.5$ と3点の比較 $[0.75,1,1.75]$ を係数 $[0.315789,-0.421053,0.315789]$ で足し、最初と同じ $0.368421$ へ。中央点の負の寄与で、単なる近隣平均ではないことを示す。
7. **特徴を隠す利点と代価**：予測式に $\phi$ が現れず、カーネルだけを差し替える見通しを示す。訓練点数 $N$ と特徴数 $M$ の行列サイズを比べ、$N\gg M$ なら計算量上の利点は自明ではないことも示す。6.2へ「どんな比較をカーネルにできるか」を残す。

物語全体は8〜13分・7シーンを目標とする。数値は原典 (6.2)–(6.9) に合わせた自作例から計算する。VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）を用いる。動画内にクレジットは表示しない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §6.1、印刷 pp.293–294（PDF pp.313–314）全文を `pdftotext -layout` で読み、該当2ページを画像で確認した。本節に図表はない。章の導入 pp.291–292 と、式 (6.1) も参照した。

[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf) は p.293 の (6.8) 直前を「(6.3) を (6.4) に代入して $a$ を解く」に訂正している。$J(a)$ の勾配0だけから一意の $a$ を断言しない。$\lambda>0$ の例では $K+\lambda I$ が可逆である。

採用しない項目：パーセプトロンの双対表現、ガウス過程とSVMの詳細、任意のカーネルの有効性判定。いずれも本節では次章・次節への予告にとどまる。

## 数値例と近似の条件

- 自作3点 $x=(-1,0,1)$、目標 $t=(1,0,1)$、$\phi(x)=(1,x,x^2)^T$、$\lambda=0.5$。近い2点の平均 $0.5$ は冒頭の素朴な予想で、学習アルゴリズムの出力ではない。
- $\Phi$ の3行は $(1,-1,1),(1,0,0),(1,1,1)$。$K=\Phi\Phi^T=\begin{pmatrix}3&1&1\\1&1&1\\1&1&3\end{pmatrix}$。$w=(0.210526,0,0.631579)$、$a=(0.315789,-0.421053,0.315789)$。
- 新点 $x_*=0.5$ に対し $k(x_*)=(0.75,1,1.75)^T$。$w^T\phi(x_*)=k(x_*)^Ta=0.368421$。表示値は丸め値。計算は浮動小数点の `numpy.linalg.solve` で行い、厳密一致は検証時の許容誤差で評価する。
- $k(x,x')=1+xx'+x^2x'^2$ は指定した有限次元特徴の内積。この例だけから任意の対称関数を有効なカーネルとみなさない。

# PRML 6.2 カーネルの構成

## 物語の設計

全編の問いは「近い点ほど大きい、対称で、値が0から1に収まる比較なら、6.1の予測式へ入れてよいか」。6.1で用いた3点 $x=(-1,0,1)$、目標 $t=(1,0,1)$、新点 $x_*=0.5$ を引き継ぐ。冒頭では $s(x,z)=1-(x-z)^2/4$ を3点の比較表にして、すべてのセルが0から1なら使えそうだと予想させる。ところが係数 $(1,-1.5,1)$ に対する二次形式は $-0.25$。内積から作る表では起こらない負の「長さの二乗」である。どうすれば確かめ、使える比較を設計できるかを追う。

1. **予想と異変**：6.1の予測式を一言でつなぐ。同じ3点の距離から作った比較表を示し、使えるか予想する。表の値はすべて非負なのに、重み付きの合計が負になる。
2. **比較の正体**：6.1の特徴・内積を短く想起する。特徴を並べて対応する成分を掛けて足すと、どんな重み付きの合計も長さの二乗になり非負。Σと内積・二次形式は小さな本文カードで操作を見せる。
3. **使えるかの検査**：3点のGram行列で $c^TKc=-0.25$ を実際に展開する。対称・セルの非負だけでは足りず、任意の点集合で半正定値が必要と示す。1組の失敗は反例だが、有限の成功例だけでは一般の有効性を証明しない。
4. **作り方その1**：$\phi(x)=(1,\sqrt2x,x^2)^T$ から $k_P(x,z)=(1+xz)^2$ を作る。二次の展開で交差項の $\sqrt2$ の役割を図解。入力を動かし、基底の成分と比較曲線が一緒に変わる。
5. **作り方その2**：既知の有効なカーネルの和・積と非負係数の多項式を材料として組み立てる。$1+xz$ の二乗をこの経路からも確認。式の羅列ではなく、同じ3点の比較表が合成される様子を見せる。
6. **距離を使いたい**：ガウスカーネル $k_G(x,z)=\exp(-(x-z)^2/(2\sigma^2))$ で距離に応じた山を動かす。$\sigma$ つまみで幅を変える。原典の式 (6.24)–(6.25) に従い、指数を3因子へ分けて有効性の根拠を示す。確率密度ではないため正規化係数は付けない。
7. **冒頭への回帰**：同じ3点、$x_*=0.5$、$\lambda=0.5$ に戻す。$k_P$ は6.1と同じ $0.368421$、$\sigma=1$ の $k_G$ は $0.431040$。比較の選択が予測を変えることを同じ軸の曲線切替で確かめ、6.3の「距離の山を予測にどう使うか」へつなぐ。

全7シーン、音声実測で約8分08秒。視覚補足と復習は本編の15%以内とする。VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）を使い、クレジットは動画外の本READMEに記す。

## 視覚補足と章をまたぐ復習

- 同章6.1は独立した復習カードを置かず、最初の予測式と3点を一言でつなぐ。
- シーン2で「3.1 入力から特徴へ」の節番号付き復習カード R を17.2秒。既存3.1の入力の青、基底の緑、操作の黄を縮約して再現する。過去節を import しない。
- シーン2のΣ・内積とシーン3の二次形式は、青い項→黄色の乗算→緑の合計を動かす本文カードを使う。半正定値の必要な意味だけを示し、3点の反例計算は本筋の実験として扱う。
- シーン4の交差項の $\sqrt2$、シーン6の指数の3因子への分解を本文カードで見せる。いずれも直後の曲線・有効性へ接続する。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §6.2、印刷 pp.294–299（PDF pp.314–319）の全文を `pdftotext -layout` で確認し、図6.1のある印刷p.295を画像で確認した。公式正誤表は図6.1とキャプションを差し替え、参照位置 $x'$ を赤い×で示すよう訂正する。動画の図は固定点を明示し、旧版図の波形をそのまま模写しない。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf) の p.297 の訂正は、式 (6.27) の $|A|$ が「部分集合の数」ではなく「要素数」である点。本編で集合カーネルを扱わないが、参照時は訂正版に従う。

本編で選ぶ範囲は特徴からの構成、半正定値判定、和・積、ガウスカーネル。集合・文字列・生成モデル・Fisher・シグモイドの各カーネルと (6.27)–(6.37) は、1本の物語に詰め込まず採用しない。特にシグモイド形は一般には有効なカーネルとは限らない。

## 数値例と近似の条件

- 自作3点 $x=(-1,0,1)$、$t=(1,0,1)$、$x_*=0.5$、正則化係数 $\lambda=0.5$。6.1の例をそのまま引き継ぐ。
- 失敗例 $s(x,z)=1-(x-z)^2/4$ は、この3点上では対称かつ全セルが $[0,1]$ にある。$K_s=\begin{pmatrix}1&0.75&0\\0.75&1&0.75\\0&0.75&1\end{pmatrix}$、$c=(1,-1.5,1)^T$ で $c^TK_sc=-0.25$。$s$ を有効なカーネルと呼ばない。
- $k_P(x,z)=(1+xz)^2$ は $\phi(x)=(1,\sqrt2x,x^2)^T$ の内積。6.1の $1+xz+x^2z^2$ とは違う式だが、この対称な3点・同じ目標と正則化に限って新点の予測は同じ $7/19\approx0.368421$。一般に2つのカーネルが同じ予測を与えるとは主張しない。
- $k_G(x,z)=\exp(-(x-z)^2/(2\sigma^2))$ は1次元・$\sigma=1$ を主例とし、$\lambda=0.5$ の双対回帰で $y(0.5)\approx0.431040$。途中の幅変更は別の設定として示す。$\sigma=0.7$ では $y(0.5)\approx0.374444$、$\sigma=1.2$ では $y(0.5)\approx0.471441$。幅を元の1へ戻してから締めくくる。表示値は丸め値で、計算は `numpy.linalg.solve` を使う。
- 半正定値条件は任意の有限な点集合と任意の実係数ベクトルに対して課す。1組の負値で無効性が証明できるが、有限の点集合での非負確認だけでは一般の有効性を証明できない。

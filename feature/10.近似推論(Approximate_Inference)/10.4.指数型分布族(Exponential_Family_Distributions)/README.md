# PRML 10.4 指数型分布族

## 物語の設計

全編の問いは「出所が分からない12件の計数データのうち、3回という観測はどちらの発生源から来たのか。その迷いを捨てずに、2つの発生率をどう学ぶか」。低頻度・高頻度の2台が等確率で選ばれ、各台の発生回数がポアソン分布に従う自作例を使う。冒頭で `3` は低頻度側に見えるか、半々かを予想してもらう。途中で潜在変数の責務、期待十分統計量、共役事前、交互更新を順に発見する。結末では同じ12件・同じ `3` に戻り、実測した責務と更新後の発生率で答える。

10.3 の係数と精度の交互更新を、2.4 で見た指数型分布族の共通形へ拡張する。数式は観測点、責務の棒、分布曲線、有向グラフと同時に置く。つまみで一つのグラフの値を変え、予想の間を挟む。装飾枠・台・影をグラフ背面に置かない。8シーン、8〜13分を目指す。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §10.4、印刷pp.490–492（PDF pp.510–512）の全文を抽出して読み、該当3ページを画像で確認した。本文が参照する図10.5（印刷p.475、PDF p.495）と図8.26（印刷p.383、PDF p.403）も画像で確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)の p.490–492 の訂正を確認した。特に (10.114) の `χ₀`、(10.118) と (10.119) の `ν` の係数、(10.121) の `ν_N χ_N = ν₀χ₀ + ΣE[u]` を採用する。図10.5はガウス混合の例であり、動画には今回のポアソン混合に対応した自作の有向グラフを描く。局所更新の説明は (10.122)–(10.124) に沿う。

原典の一般の指数型分布族と、全ての変数を因子化したグラフの更新を、ポアソン混合の小例に絞って説明する。変分メッセージ伝播の汎用ソフトウェアや下界の詳細な計算、分布族の全例は尺のため省く。

## 数値例と近似の条件

- 自作の12件は `[0,1,0,2,1,0,2,3,5,6,7,8]`。観測の順序は推定に影響しない。2台の選択確率は既知で各0.5、各台の回数は条件付きポアソン分布。低頻度側の発生率は Gamma(形状1, 率1)、高頻度側は Gamma(形状6, 率1) とする。異なる事前平均1と6はこの例の装置に関する仮定であり、データだけから与えた事実ではない。
- 変分近似は `q(Z)q(λ₁)q(λ₂)`。初期責務は回数3.2を境にした滑らかな説明用初期値で、18巡の座標更新を行う。低頻度・高頻度のラベルは異なる事前分布で区別する。
- `E[log λ]` には digamma を使う。`log E[λ]` で代用しない。初期責務の高頻度側は3回の観測で0.386986。18巡後の変分責務は0.765283、率の事後平均は0.850157と5.435341。3回から高頻度側へ渡す重み付き回数は2.295849。担当件数は6.435857と5.564143、重み付き回数の和は5.321645と29.678355。
- 変分責務は真の事後周辺確率と同一ではない。12件なら全 `2^12` 通りの所属を和で消去でき、この例の厳密な高頻度側事後確率は0.724066。動画の約0.77は変分近似の結果として一貫して扱う。

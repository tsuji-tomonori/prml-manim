# PRML 10.7 期待値伝播

## 物語の設計

全編の問いは「同じ観測点を見たのに、読む順番だけでガウス近似の中心が変わる。古い近似をどう直すか」。自作の1次元クラッタ例で、信号候補4点 $4.2,4.8,5.1,5.4$ と背景候補 $-3.0$ を使う。1回だけ更新する ADF では、左からの順で事後平均が約 $5.131$、逆順で約 $4.327$。視聴者に結果を予想させ、同じデータの順序で差が出る理由を追う。1因子を外して真の尤度を入れ直し、平均と分散を合わせる期待値伝播（EP）へ進む。最後に同じ5点で EP の平均約 $4.879$ を示し、有限個なので計算できる真の事後平均約 $4.865$ と照合する。

10.6 の「ガウスで近似した重みの雲を得る」という問いを受け、今回は近似する向きと因子の更新法を変える。データを表す数直線と、$\theta$ の密度グラフを画面内に保つ。青は近似、黄は現在の更新、緑は更新結果、紫は事前、赤は真の因子・比較対象とする。軸の背後に枠・台・影を置かず、奥行きは加えない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §10.7、印刷pp.505–517（PDF pp.525–537）を通読し、図10.14〜10.18をPDF画像で確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)の該当箇所も確認した。特に p.509 の cavity 添字は $j$、(10.217)(10.218) 左辺は $m^{new},v^{new}$。説明では訂正後の記号を使う。p.515 の (10.228) は等号ではなく比例記号という訂正も確認した（動画では省略）。[日本語版の和文索引](https://ibisforest.org/index.php?openfile=prml-jp-jp_index.pdf&plugin=attach&refer=PRML)で「仮定密度フィルタリング」と「期待値伝播法 → EP法」の訳語を確認し、タイトルと前節の予告に合わせて「期待値伝播」と表記した。原典のグラフ実測値を読み取って自作例の値として使わない。指数型分布族の一般証明、モデル証拠の定数因子、(10.214)–(10.224) の全パラメータ式、グラフ上の EP と積和アルゴリズムの等価性は尺のため省く。

## 数値例と近似の条件

- 1次元の自作例。$p(x\mid\theta)=0.5\mathcal N(x\mid\theta,1)+0.5\mathcal N(x\mid0,10)$、$p(\theta)=\mathcal N(\theta\mid0,100)$。これは原典 (10.209)(10.210) の $D=1,a=10,b=100,w=0.5$ で、観測値は自作。
- 復習カード1.6の棒は説明用の離散分布 $[0.4,0.3,0.2,0.1]$ と $[0.2,0.4,0.3,0.1]$、2.3の曲線は説明用の $\mathcal N(0,1)$。モーメント補足の4位置の重みは $[0.12,0.23,0.42,0.23]$。いずれも冒頭の5点から計算した量ではない。
- 初期近似因子はすべて1。ADF は各因子を指定順に1回更新し、EP は複数巡で更新する。各更新では cavity と真の因子の積を正規化した分布の平均・分散へガウスを合わせる。更新中の個別因子は確率密度とは限らず、負の精度も許す。全体のガウスの分散は正の条件で用いる。
- 冒頭の数値は浮動小数点計算の丸め。真の事後は5因子の積を1次元の無限区間で数値積分し、比較用の基準とする。短い区間で積分を打ち切ると裾の質量を落とすため、分散が過小になる。左端 $-3$ を最後に読んだ初回順方向で、その点が背景ではなく信号である更新時の重みは約0.001564509。シーン5の支点図は、この更新時の信号側平均−1.205749と背景側平均5.141258を描き、重み付き平均5.131328を緑で示す。EPの8巡後は順方向・逆順とも平均約4.879328716。真の平均は4.865049007、EPとの差は約0.014280。EP分散0.308510729に対し真の分散0.567643158である。EP が一般に厳密値へ一致するとは主張しない。EP の収束も一般には保証しない。真の積分は `scipy.integrate.quad` の無限区間、絶対誤差目標 $10^{-12}$、相対誤差目標 $10^{-11}$。数値実験の更新は正規化したキャビティを使い、因子の尺度定数とモデル証拠は計算対象外。傾いた分布の平均・分散は解析式と独立な数値積分で照合する。

# PRML 10.2 例：変分ガウス混合

## 物語の設計

全編の問いは「2つの点群に6個のガウス成分を用意したとき、余分な4個はなぜ小さくなるのか」。冒頭では自作の2次元観測を見せ、6個の輪郭をそのまま残すかを予想する。10.1 の平均場更新を「所属の確率」と「成分パラメータの分布」の交互更新へ移し、点が輪郭へ渡す責任の総量、事前とデータの綱引き、下界の上昇を同じ点群で追う。結末では冒頭と同じデータ・初期候補・事前へ戻り、実際に残った成分の重みで問いへ答える。

動画は8〜13分・8シーンを目標とする。式の各項を点・負担率の棒・楕円の幅に結び、点群を背景として保つ。グラフ背面の装飾枠・台・影は用いず、復習カードだけ右側に細い黄色の枠を使う。説明文は日本語、個数と番号はアラビア数字で表示する。音声は VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §10.2、印刷 pp.474–486（PDF pp.494–506）の全文を `pdftotext -layout` で読み、図10.5〜10.7をPDF画像で確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)の p.474、p.479、p.483、p.484 を確認した。特に (10.69) の分子は `α₀ + Nₖ`、(10.80)–(10.81) の等号は近似記号として扱う。図10.7への参照も正誤表どおりにする。

予測密度と自動的な成分縮小を物語へ含める。下界 (10.70)–(10.77) の全項の式展開、モデル数を変えて比較するときの `ln K!` 補正、点推定による成分刈り取り (10.83)、誘導された因子分解 (10.84)–(10.86) の証明は尺のため扱わず、本文の要点をここに記録する。下界による異なる `K` の比較は同じモデル内の成分縮小とは別の操作である。

## 数値例と近似の条件

- 自作の2次元・2群データ、各40点（計80点、`seed=1023`）を使用する。生成母集団の平均は `[-1.65,-0.65]` と `[1.75,0.75]`、共分散は `[[0.28,0.13],[0.13,0.24]]` と `[[0.31,-0.08],[-0.08,0.22]]`。原著の Old Faithful データや図10.6の座標は転写していない。
- 開始時の成分数は `K=6`。初期の所属確率は `INITIAL_CENTERS` から距離尺度0.40の softmax で作る。事前は `α₀=0.001`、`β₀=0.05`、`ν₀=3`、`m₀=(0,0)`、`W₀=1.5I`。これらは原著の図10.6の設定そのものではない。
- 負担率と更新は (10.46)–(10.66) に従う。初期の混合係数の平均は `[0.14224,0.25392,0.09430,0.05648,0.33442,0.11864]`。30巡後は成分2と5が `[0.499979,0.499971]`、他の4成分が各 `0.000012499`。有効個数は成分2が `40.000316`、成分5が `39.999684`、他は数値上0。合計は80。
- 下界は (10.70) の7項を個別に計算し、初期 `−254.561752` から30巡後 `−193.886164` へ上がる。50巡までの最小ステップ変化は浮動小数点誤差の `−3.13×10⁻¹³`。固定した `K` と事前での更新前後を比較する。モデル間比較の下界と混同しない。
- 成分の「消失」は有限の正の `α₀` では厳密な重み0ではない。票が0なら重みは `α₀/(N+Kα₀)=0.000012499`。成分の中心・精度の変分分布も事前へ戻る。事前だけ `α₀=10` に変えて同じ初期所属から再学習すると、30巡後の6重みはおよそ `0.14–0.19` に分散する。事前によって成分が残る結果は変わる。
- 輪郭は `mₖ` を中心に `E[Λₖ⁻¹]` の1標準偏差の楕円を描く。`νₖ≤D+1` ではこの期待値は発散するため、票のない成分の輪郭は表示上消す。描画用の有限な代替値を確率量として読まない。
- 予測密度は真のパラメータ事後を変分事後で置き換えた近似で、各成分は自由度 `νₖ+1−D` のスチューデントの t 分布。映像の緑の曲線はその `x₁` 周辺密度。紫は中心を `mₖ`、精度を `E[Λₖ]` に固定したプラグインのガウス混合で、予測分布のもう一つの厳密解ではない。自由度と尺度は (10.81)–(10.82) に従う。

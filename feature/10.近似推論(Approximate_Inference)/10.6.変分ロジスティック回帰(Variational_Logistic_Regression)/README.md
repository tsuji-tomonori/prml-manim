# PRML 10.6 変分ロジスティック回帰

## 物語の設計

全編の問いは「学習点と同じ横位置 $x=1.4$、しかし縦方向に離れた $(1.4,4)$ で、1本の境界からの予測約0.960を信じてよいか」。2クラスの自作データ10点を使い、変分事後の重みを平均した値約0.744との食い違いを冒頭で予想する。10.5の局所下界を各観測のシグモイドに置くと、曲がった尤度が重みについて二次式になり、ガウス事後を更新できる。接点も事後の広がりから更新し、両者を往復する。最後に同じデータ・同じ入力へ戻り、境界から遠くても学習点から遠い場所では予測の自信が下がることを確認する。

10.5の「1つのシグモイドを積分しやすい下界へ変える」という問いを受け、今回はそれを全訓練例へ適用する。グラフは一つの分類平面を保ち、候補境界と予測等高線を切り替える。青は入力と近似、黄は操作、緑は更新結果、紫は事前、赤は元の尤度・データという色の役割を使う。グラフ背面の装飾枠・台・影は置かない。

## 視覚補足と章をまたぐ復習

- シーン2で「復習: 4.5 ベイズロジスティック回帰」を約12秒。重みの候補から境界の候補を作り、確率を平均する元節の操作だけを再現する。字幕 `display` は `4.5`、音声 `speech` は「四章五節」。過去節は import しない。
- シーン3で、10個の積を対数で和に変える操作を約10秒、点ごとの短い棒から1本の二次曲線へつなぐ。
- シーン4で、$\phi^T S\phi$ が入力方向への広がりであることを約12秒の小窓で図解する。シーン5の期待値は平均と幅の2本の棒で示す。補足・復習は本編の15%以内にする。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §10.6、印刷pp.498–505（PDF pp.518–525）を通読し、図10.13をPDF画像で確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)のpp.501–505に従う。(10.164)の符号、(10.177)のガンマ分布パラメータ、(10.183)の転置を訂正する。二値分類の下界であり、多クラスへそのまま適用する主張はしない。逐次学習と下界を積分して直接最適化する別経路は尺のため詳述しない。

## 数値例と近似の条件

- 自作データは左クラス5点・右クラス5点。$\phi=(1,x,y)^T$、ラベルは0/1、固定ガウス事前は $N(0,\alpha^{-1}I)$、$\alpha=0.4$。座標と反復停止条件は `variational_logistic_model.py` に固定する。これは原典図10.13のデータを転写したものではない。
- 各データの $\xi_n>0$ に対し $\lambda(\xi_n)=\tanh(\xi_n/2)/(4\xi_n)$ を使う。10.5の訂正後の下界と符号を揃える。正規化した $q(w)$ 自体は元の事後への点ごとの下界ではない。
- 代表重みでの $(1.4,4)$ の予測は約0.959890。変分ガウス事後の予測を120点Gauss–Hermiteで積分すると約0.743530。4.5の $\kappa$ 近似は約0.742395で、動画の約0.744は前者を丸めた値。真のベイズ事後予測の厳密値と呼ばない。
- $y=0$ の同じ横位置では変分事後平均の予測が約0.936412。$y=4$ との差は、このデータと事前と変分近似の条件下で生じる。一般に学習点からの距離だけで予測分散が単調増加するとは言わない。

# PRML 10.5 局所変分法

## 物語の設計

全編の問いは「説明用の分類スコアの平均が1で、代表値をシグモイドに入れると約0.73。それでもスコアに幅があるとき、確率の平均を計算しやすい形で、どこまで確実に下から押さえられるか」。冒頭と結末には同じ自作例 `a ~ N(1, 2²)` を使う。実際のガウス平均は約0.648、局所変分下界を最適化した値は約0.600。代表値から出す約0.731との違いを予想させ、曲線に接する直線を動かす実験から二次式の下界を発見し、最後に同じ分布の面積へ戻る。約0.600は平均確率そのものと断定せず、保証された下界として示す。

10.4での全体分布の因子更新から、「計算を難しくする1つの因子だけを扱えないか」という問いを受け継ぐ。シグモイドとその下界を同じ座標で重ね、接点・変分パラメータのつまみ・積分の面積を発話中に動かす。結末でも冒頭のシグモイドを同じ座標に残し、同じ分布から得た3つの数値を横棒で示す。装飾枠、台、影は置かない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §10.5、印刷pp.493–498（PDF pp.513–518）を `pdftotext -layout` で通読し、図10.10–10.12を含むpp.493–497を画像で確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)にある原典pp.493–497の訂正を参照した。原著初版の接線・双対パラメータ `λ` は正誤表に従って `η` と記す。シグモイド下界では `λ(ξ)=tanh(ξ/2)/(4ξ)>0` とし、`η=-λ`。原著初版の式(10.141)–(10.143)の負号をそのまま採用しない。表示する式(10.144)と数値計算も、この訂正と整合させる。

対数シグモイドの上界(10.132)–(10.137)は境界の向きの比較に絞り、二値エントロピーの導出は省く。多クラス softmax への拡張案、グラフ全体への汎用適用、10.6の事後更新は尺のため詳述しない。

## 数値例と近似の条件

- 自作例のスコアは `a ~ N(1,4)`。代表値を使う `σ(E[a])=0.731058579` と、ガウス密度で平均した `E[σ(a)]=0.647726439` は異なる。数値積分で計算し、画面では0.731・0.648に丸める。
- 下界 `B(a,ξ)=σ(ξ) exp((a-ξ)/2 - λ(ξ)(a²-ξ²))` とする。`ξ>0`、`λ(ξ)=tanh(ξ/2)/(4ξ)`、`λ(0)=1/8`（連続極限）。すべての実数 `a` で `B≤σ`、接点 `a=±ξ` で一致する。
- `F(ξ)=E[B(a,ξ)]` の最良値はこの自作例で `ξ≈2.331912`、`F≈0.599663`。これは固定 `ξ` を全 `a` に共用した積分下界であり、各 `a` ごとに接点を変えて得る点ごとの一致とは異なる。動画の約0.600はこの例での数値最適化結果で、一般的な精度保証ではない。
- シーン5の紫の指数型上界は、確率軸の表示範囲（0〜1.06）で線を切っている。上界自体は1を超えうる。
- シーン3の `exp(-x)` は凸双対の説明用の別関数。接点を動かす範囲を明示する。シーン6の `ξ=2.5` は原典図10.12に合わせた説明用の値で、最終積分の最適値ではない。

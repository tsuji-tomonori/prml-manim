# PRML 10.5 局所変分法

## 物語の設計

全編の問いは「平均スコアが1の分類で、代表値をシグモイドに入れると約0.73。それでもスコアに幅があるとき、確率の平均を計算しやすい形で、どこまで確実に下から押さえられるか」。冒頭と結末には同じ自作例 `a ~ N(1, 2²)` を使う。実際のガウス平均は約0.648、局所変分下界を最適化した値は約0.600。代表値から出す約0.731との違いを予想させ、曲線に接する直線を動かす実験から二次式の下界を発見し、最後に同じ分布の面積へ戻る。約0.600は平均確率そのものと断定せず、保証された下界として示す。

10.4での全体分布の因子更新から、「計算を難しくする1つの因子だけを扱えないか」という問いを受け継ぐ。シグモイドとその下界を同じ座標で重ね、接点・変分パラメータのつまみ・積分の面積を発話中に動かす。結末も冒頭の同じ分布とシグモイドを画面に残す。装飾枠、台、影は置かない。

## 視覚補足と章をまたぐ復習

- シーン1で「復習: 4.5 ベイズロジスティック回帰」を約12秒。元節の青いスコア分布、赤いシグモイド、黄色い積の面積を必要な部分だけ再現し、今回の `N(1,4)` に対応させる。参照元の節番号は字幕で `4.5`、読みで「四章五節」。
- シーン3で接線の微分を約12秒。青い曲線上の点を動かし、黄色い接線の傾きが変わることを示す。シーン4の `max` は候補を選ぶ動きで示し、独立カードを追加しない。
- シーン6で `x²` を同じ値にする `+ξ` と `-ξ` を約12秒。二乗の小窓から左右の接点へ対応線を伸ばす。シーン7の積分は、同じ横軸の密度と下界の積を幅ごとの棒で足す約15秒の図解とする。
- 10.1・10.2・10.4は同じ章なので独立の復習カードを作らず一言でつなぐ。補足と復習の合計は本編の15%以内を目指す。配色は青が元の量、黄が操作、緑が結果、紫が比較。復習元の図形だけを再現し、過去節のコードを import しない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §10.5、印刷pp.493–498（PDF pp.513–518）を `pdftotext -layout` で通読し、図10.10–10.12を含むpp.493–497を画像で確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)のpp.493–497を参照した。原著初版の接線・双対パラメータ `λ` は正誤表に従って `η` と記す。シグモイド下界では `λ(ξ)=tanh(ξ/2)/(4ξ)>0` とし、`η=-λ`。原著初版の式(10.141)–(10.143)の負号をそのまま採用しない。表示する式(10.144)と数値計算も、この訂正と整合させる。

上界の二値エントロピー式(10.135)–(10.137)は、下界と向きが違うことを見せる範囲に絞る。多クラス softmax への拡張案、グラフ全体への汎用適用、10.6の事後更新は尺のため詳述しない。

## 数値例と近似の条件

- 自作例のスコアは `a ~ N(1,4)`。代表値を使う `σ(E[a])=0.731058579` と、ガウス密度で平均した `E[σ(a)]=0.647726439` は異なる。数値積分で計算し、画面では0.731・0.648に丸める。
- 下界 `B(a,ξ)=σ(ξ) exp((a-ξ)/2 - λ(ξ)(a²-ξ²))` とする。`ξ>0`、`λ(ξ)=tanh(ξ/2)/(4ξ)`、`λ(0)=1/8`（連続極限）。すべての実数 `a` で `B≤σ`、接点 `a=±ξ` で一致する。
- `F(ξ)=E[B(a,ξ)]` の最良値はこの自作例で `ξ≈2.331912`、`F≈0.599663`。これは固定 `ξ` を全 `a` に共用した積分下界であり、各 `a` ごとに接点を変えて得る点ごとの一致とは異なる。動画の約0.600はこの例での数値最適化結果で、一般的な精度保証ではない。
- シーン3の `exp(-x)` は凸双対の説明用の別関数。接点を動かす範囲を明示する。シーン6の `ξ=2.5` は原典図10.12に合わせた説明用の値で、最終積分の最適値ではない。

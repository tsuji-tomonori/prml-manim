# PRML 10.3 変分線形回帰

## 物語の設計

全編の問いは「10個の観測から、範囲外の $x=1.35$ を予測するとき、事前の強さ $\alpha$ を誰が決め、予測の幅をどう残すか」。3次式から自作した10点を同じ軸に置き、まず曲線を伏せて右端の高さを予想する。冒頭では事前精度を0.01と100に切り替え、同じ点でも外挿値が約2.44から1.24へ変わる。視聴者が強さの選択を予想したあと、$\alpha$ 自体に分布を置く実験へ進む。10.2 の所属と成分の交互更新を、回帰係数 $w$ とその事前精度 $\alpha$ の交互更新へつなぐ。結末は同じ10点・同じ $x=1.35$ に戻り、$E[\alpha]$、予測平均、2種類の分散で答える。

予定は8シーン、8〜13分。曲線と点を常に主役とし、式は係数の分布・予測帯・下界の動きの近くへ置く。グラフ背面に装飾枠・台・影を置かない。説明文は日本語、個数・番号・倍率はアラビア数字。音声は VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）。

## 視覚補足と章をまたぐ復習

- シーン2で「復習: 3.3 ベイズ線形回帰」。係数候補から曲線候補が広がる図を必要部分だけ再現する。
- シーン3で「復習: 2.3 ガンマ分布」。正の精度の候補と確率密度を結ぶ。
- シーン4で期待値を重み付き平均の短い図解にし、$E[w^Tw]=m_N^Tm_N+\mathrm{Tr}(S_N)$ の広がり項を見せる。
- シーン6で「復習: 3.5 エビデンス近似」。固定した1つの強さとの違いを示す。
- 同章の10.2は独立した復習カードを作らず、交互更新の一言でつなぐ。補足と復習は本編の15%以内とする。節番号の字幕は数字、発話は「三章三節」のように読む。

実測では3.3復習が61.867秒から11.467秒、2.3復習が137.533秒から11.067秒、期待値の補足が201.000秒から6.733秒、3.5復習が338.333秒から11.200秒。計40.467秒で全編494.133秒の約8.2%。復習図は元の動画全体を import せず、係数から曲線、ガンマ分布、下界の必要な図法のみ再現する。青=元の量、黄=操作、緑=結果、紫=事前、赤=生成時の値とする。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §10.3、印刷pp.486–490（PDF pp.506–510）の全文を `pdftotext -layout` で読み、図10.8・10.9を画像で確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)では p.489 の (10.110) の末項を $-\ln\Gamma(a_0)$ とし、モデル比較の文章を $\ln p(t\mid M)$ へ訂正している。図10.8の添字も確認した。下界の計算には訂正式を使う。

本編では $\beta$ は既知として固定する。予測分布と下界を扱うが、(10.108)–(10.112) の全項の手計算と次数ごとのモデル選択は尺のため省く。原典図10.9は次数選択の例であり、本編の固定3次モデルの反復をそれと同じ結果として扱わない。$a_0=b_0=0$ の形式的な非情報事前ではなく、比較可能な正の値を使う。

## 数値例と近似の条件

- 自作の3次式 $0.2+0.8x-0.1x^2+0.55x^3$ から、$x=-1$ から $1$ の等間隔10点を作る。独立な正規雑音の標準偏差は0.3、乱数 seed は1030。原典図10.9の点を転写しない。
- 基底は $(1,x,x^2,x^3)$、$\beta=1/0.09$ を既知とする。$\alpha$ の事前は形状・率とも0.05の適切なガンマ分布。係数の事前は $\mathcal N(0,\alpha^{-1}I)$ で、切片も縮める。
- 因子化近似 $q(w)q(\alpha)$ の座標更新は(10.94)–(10.103)。初期 $E[\alpha]=1$ から25巡計算し、下界は(10.107)を正誤表の(10.110)で評価する。
- $x=1.35$ で固定 $\alpha=0.01$ の予測平均は約2.442、固定100では約1.242。25巡後の $E[\alpha]$ は約1.882、予測平均は約2.347。観測予測分散はノイズ0.09と係数0.5031の和。標準偏差は約0.770。
- 生成に用いた雑音なしの値は約2.451。学習に使わない答え合わせ用の値で、外挿の正確さを一般化しない。表示する帯は各 $x$ における平均±1標準偏差で、曲線全体を同時に含む区間ではない。
- 青い候補曲線4本は、更新途中の $q(w)$ から乱数 seed 33 で描いた例。グラフの範囲外は表示しない。右側のガンマ曲線は確率密度であり、高さそのものは確率ではない。
- 3.5 復習の紫の証拠曲線は、今回の自作10点を使い、$\alpha$ を固定して $w$ を積分した対数エビデンスを描く。表示した探索格子では最大点の $\alpha$ は約1.995。これは変分更新の約1.882とは別の計算で、3.5 の元動画の18点や選択値を今回の結果として使わない。変分下界の曲線は同じ固定3次モデルでの反復を示す。

# PRML 7.1 最大マージン分類器

## 物語の設計

[完成動画（480p15）](media/videos/prml_7_1_maximum_margin_classifiers/480p15/PRML71MaximumMarginClassifiers.mp4) ／ [全文台本](narration_script.md) ／ [全文の読み確認](reading_check.md)

全編の問いは「同じ6点をどちらも正しく分ける2本の線のうち、なぜ中央の線を選ぶのか」。前章から「カーネルの予測に、多くの点を参照する必要があるか」という問いを受け継ぐ。青と緑の6点を示し、全点正解の境界 $x_1=0.4$ で十分かと予想させる。最も近い点までの距離は $0.6$。中央の $x_1=0$ でも全点正解だが、距離は $1$ に広がる。その差を垂直距離、尺度の固定、制約、双対、サポートベクトルの順に調べる。外側の4点を動かしても境界が変わらない実験から、学習後に必要な点が絞られる理由へ進む。重なった点ではソフトマージンを導入し、$C$ と境界・余白を同時に動かす。最後は冒頭と同じ6点、同じ2本の線、同じ距離に戻り、途中の発見で問いに答える。結末と7.2への予告も、点群と境界を残したまま示す。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning*, 章導入 p.325、§7.1 印刷 pp.326–345（PDF pp.346–365）を `pdftotext -layout` で全文確認。図7.1–7.8をPDF画像で確認し、採用した図7.1・7.3・7.5は拡大して照合した。図・数値は自作例から再構成し、原図の学習データを転写していない。

[公式正誤表（2011-09-21）](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)では、p.329の双対目的について「bounded above」、p.332の(7.22)の引数 $L(w,b,\xi,a,\mu)$、p.333の双対問題を「maximize」とする訂正を確認した。数値計算では双対目的を最大化することと、その負を最小化することを対応させている。

本編は硬いマージン、双対の意味、予測のスパース性、ソフトマージン、ヒンジ損失に絞った。Lagrangianの偏微分の逐行導出、閾値 $b$ の平均式、ν-SVM、SMOなどの実装、多項式特徴の多様体、確率校正、7.1.2のロジスティック回帰との詳しい比較、7.1.3の多クラス、7.1.4の回帰、7.1.5のPAC理論は省いた。最大マージンが任意の未知データで正解を保証するとは説明しない。

## 数値例と近似の条件

- 線形の主例は自作6点。負のクラス $(-1,0),(-2,-1),(-2,1)$、正のクラス $(1,0),(2,-1),(2,1)$。2本の候補境界 $x_1=0.4$ と $x_1=0$ は全6点を正しく分類し、最短垂直距離はそれぞれ0.6と1。後者は $w=(1,0),b=0$、係数は $a=(0.5,0,0,0.5,0,0)$。反対クラスの最近接2点の間隔が2なので、任意の分離直線の余白は1以下であり、この解が達成する。
- scene04では外側の4点だけを余白の外側で移動し、元へ戻す。内側の2点と境界は動かさない。結末でも移動は往復させ、冒頭と同じ座標に戻す。接している制約すべてが必ず正の係数を持つという一般的主張はしない。
- scene05の説明用カーネルは $\phi(u)=(u_1-0.22\sin(2u_2),u_2)$、$k(u,v)=\phi(u)^T\phi(v)$。表示点は主例の各 $(x_1,x_2)$ を $(x_1+0.22\sin(2x_2),x_2)$ に移す。特徴空間の6点とGram行列は元と同一なので、同じ係数から $y(u)=u_1-0.22\sin(2u_2)$ と境界が得られる。ここで最大化する余白は**特徴空間**の距離。ガウスカーネルの学習結果と装う図ではない。
- scene06・07では負のラベルを持つ $(1.4,0)$ を追加する。この点は正のクラスの三角形の内部にあるため、7点を完全に分ける直線はない。scene06の $\xi_7=2.4$ は、比較用に $w=(1,0),b=0$ を固定したときの値。scene07の学習結果とは区別する。緑の点の一時的な移動はずれの説明用で、数値最適化のデータへ混ぜない。
- ソフトマージンはSciPy SLSQPで線形カーネルの双対を解く。$C=0.2$ では $w\simeq(0.52,0),b\simeq-0.04$、境界 $x_1\simeq0.076923$、余白 $1/\|w\|\simeq1.923077$。非零のずれは $(0.44,0.52,1.688)$、合計2.648。
- つまみの停止位置 $C=0.2,0.5$ でそれぞれ最適化する。途中の線の移動は2解をつなぐ表示補間で、途中の全設定を再学習する映像ではない。
- $C=0.5$ では $w\simeq(2/3,0),b\simeq-1/3$、境界 $x_1=0.5$、余白1.5。どちらも追加点は誤分類される。$C$ を大きくしても必ず全点正解になる例ではない。
- $\xi_n=\max(0,1-t_ny_n)$ は正準化した**得点のずれ**。特徴空間の距離に直すと $\xi_n/\|w\|$ となる。棒の高さは得点のずれに比例する。ハードマージンの主例では $\|w\|=1$。
- 予測の省略は学習後に係数が0と分かった点へ適用する。学習には全点を使う。サポートベクトル数が常に少ない保証はなく、出力の符号も事後確率ではない。

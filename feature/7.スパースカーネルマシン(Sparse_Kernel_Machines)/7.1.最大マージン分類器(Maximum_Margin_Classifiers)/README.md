# PRML 7.1 最大マージン分類器

## 物語の設計

全編の問いは「同じ6点をどちらも正しく分ける2本の線のうち、なぜ中央の線を選ぶのか」。前章のカーネル法では予測に多くの学習点を使った。ここでは境界を決める少数の点を探す。冒頭で左右の6点を示し、境界を $x_1=0.4$ に置く。全点が正解ならそれで十分かと予想させ、点と境界との最短距離が $0.6$ しかない違和感を見せる。中央の $x_1=0$ なら距離は $1$。その理由を垂直距離、尺度の固定、制約付き最適化、双対とサポートベクトルで確かめる。元の点を動かしても境界が変わらないことを実験し、重なる点ではソフトマージンが必要な理由を調べる。最後は冒頭と同じ6点、同じ2本の線、同じ距離へ戻る。結末では、境界の符号は確率ではないことを次節の問いにつなぐ。

## 視覚補足と章をまたぐ復習

- シーン1に「6.1・6.2 カーネルで点の似方を測る」復習カード R を約12秒。前章の青い点対から黄の内積、緑の値へつなぐ。
- シーン3の $\|w\|$ には、斜めの線への垂線と法線ベクトルの視覚補足を約12秒。
- シーン4の制約付き最適化には、接している制約だけが境界を止める視覚補足を約15秒。$a_n$ はこの接点に付く係数として導入する。
- シーン7の $\sum\xi_n$ は3本のずれを積み上げる約10秒の補足。合計約49秒で目標尺の15%以内とする。
- 青 `#58C4DD` は負のクラス・入力、黄 `#FFFF00` は現在注目する距離・操作、緑 `#83C167` は正のクラス・結果、紫 `#9A72AC` は比較候補、赤 `#FC6255` は余白への侵入に使う。背景に装飾枠は置かない。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning*, §7.1 印刷 pp.326–344（PDF pp.346–364）全文を `pdftotext -layout` で確認。図7.1、7.3、7.5をPDF画像で確認した。公式正誤表ではp.329の「bounded below」は「bounded above」、p.332の(7.22)の左辺、p.333の「minimize」は「maximize」に訂正される。動画は最大化の双対問題として扱う。7.1.2の多クラス、7.1.3の別形式、7.1.4の回帰、7.1.5のPAC理論の詳細は、冒頭の問いから外れるため省く。

## 数値例と近似の条件

- 自作の2次元6点を使用。負のクラス $(-1,0),(-2,-1),(-2,1)$、正のクラス $(1,0),(2,-1),(2,1)$。線形カーネル。2本の候補境界 $x_1=0.4$ と $x_1=0$ はいずれも全6点を正しく分類する。
- 余白は境界から最も近い学習点への**垂直距離**であり、上の2本ではそれぞれ $0.6$ と $1$。後者の正準表現は $w=(1,0),b=0$、サポートベクトルは $(-1,0),(1,0)$。両点の係数は $a=0.5$、他は0。
- シーン6・7で追加する重なり点は冒頭の6点とは別実験。近似と係数は実装後に数値検証して記録する。

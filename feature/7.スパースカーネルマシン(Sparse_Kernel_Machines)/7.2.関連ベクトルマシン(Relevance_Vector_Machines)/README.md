# PRML 7.2 関連ベクトルマシン

## 物語の設計

全編の問いは「11個の観測点に置いた候補のうち、2個の点だけを残して曲線と予測の幅をどう作れるか」。7.1では、分類境界を支える点だけが予測式に残った。ただし境界の得点は確率ではない。今回は同じ「少数の点で予測する」問いを回帰から調べる。11点の波形と2点だけを囲んだ曲線を冒頭に見せ、「2点では足りないはず」と予想する時間を置く。各点のガウス基底、係数ごとの事前精度、周辺尤度、1基底を外す実験、事後分布の順に発見する。終盤では同じ11点・同じ2個の中心・同じ入力 $x=0.45$ に戻り、平均と予測幅を再計算して冒頭の疑問に答える。分類での確率化と、データ範囲外での過信を次の問いとして残す。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning*, §7.2、印刷 pp.345–356（PDF pp.365–376）を `pdftotext -layout` で全文確認。図7.9–7.12をPDF画像で確認。採用図は原図のデータを転写せず自作例に置き換える。

[公式正誤表（2011-09-21）](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)を確認。(7.79)の尤度には $\beta$ を渡す。設計行列は、カーネルの $N$ 列と定数バイアス列を分ける。(7.94)の不要な絶対値記号、図7.10キャプションの誤植、p.352の添字と初期化条件、(7.118)の不要な $\beta$ に注意する。分類側の(7.118)–(7.119)は本編で使わない。

本編は回帰の核となる疎化、証拠による選択、予測分布、分類への拡張に絞る。全導関数の逐行導出、逐次アルゴリズムの高速な更新式、IRLSの計算詳細、多クラスのソフトマックス、厳密な計算量比較は省く。

## 数値例と近似の条件

- 自作11点 $x_n=0,0.1,\ldots,1$、$t_n=1.1g(x_n;0.25)-g(x_n;0.75)+\epsilon_n$（$g(x;c)=\exp[-(x-c)^2/(2\cdot0.3^2)]$）。ノイズの実現値は数値モデルに固定し、無作為標本と装わない。
- 基底は定数1と各点中心の $\exp[-(x-x_n)^2/(2\cdot0.3^2)]$。ノイズ精度は説明を明瞭にするため $\beta=40$ に固定し、この動画の例では学習しない。
- 各基底の精度 $\alpha_i$ を周辺尤度の1次元最大化で巡回更新する。これは全組合せの大域最適化の保証ではない。有限精度になるのは中心 $x=0.3,0.7$ の2列。精度はそれぞれ約0.63234、0.73933、事後平均の係数は約1.25403、−1.15920。訓練11点のRMSEは約0.02497。定数項も候補に含めるが、この例では除外される。
- 冒頭・結末の $x=0.45$ の予測は、平均0.287527、重み由来の分散0.003960、雑音分散0.025000、総分散0.028960、平均±2標準偏差は約[−0.053, 0.628]。モデルとガウス観測雑音を仮定した幅で、未知の真の関数への保証ではない。
- 分類場面は回帰の曲線へシグモイドを適用する**説明用の変換**であり、分類RVMの学習結果とは呼ばない。分類RVMではベルヌーイ尤度・ARD事前・ラプラス近似を使う構造を紹介する。
- 局所ガウス基底ではデータ範囲外の予測分散が不自然に小さくなり得る。実例では $x=1.4$ の予測分散0.025037は、学習範囲内 $x=0.45$ の0.028960より小さい。図の帯を一般的な外挿の保証に見せない。

- Python全ファイルを `py_compile`。`verify_numerics.py` で周辺尤度の1基底更新、事後分布、11点の当てはめ、予測平均と分散を独立計算で照合。台本・manifest・9 WAVのハッシュと時刻、全126文のVOICEVOX `audio_query` の読みを確認した。

- 各拍の前半・中間・後半と各場面末尾から計198フレームを抽出し、50枚の一覧画像と必要な原寸フレームを目視した。重なりを見つけた場面は修正後に全編を再レンダリングし、変更部分を再確認した。レビュー用画像はGit管理しない。
- 人が全550秒を連続再生して聴取する確認と、高解像度版のレンダリングは未実施。予測区間は指定した基底・雑音モデルの条件付きであり、真の関数を必ず含む保証ではない。

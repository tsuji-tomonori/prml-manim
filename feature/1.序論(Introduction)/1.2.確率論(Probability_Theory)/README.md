# 1.2 確率論 — 面積から、予測の分布へ

## 物語の設計（今回の改訂）

全編の問いは「選ぶ前は赤い箱が30%なのに、オレンジを1個見ただけで赤が約61.6%になるのはなぜか。その判断から次の1個をどう予測するか」です。箱は最初に1回選び、果物は毎回戻して同じ箱から引く説明用の実験です。

| 場面 | 直前からの疑問 → 実験 → 発見 |
|---|---|
| 1–3 | 青が有力なのに赤が逆転するのはなぜ？ → 赤・青の幅とオレンジの高さを掛け、残った面積を新しい全体にする → 事後確率45/73 |
| 4–5 | 果物以外の連続値では、面積をどう扱う？ → 区間・密度・幅の変換と、重心・広がりを動かす → 積分、期待値、分散 |
| 6–7 | 観測から分布の形を決めると、何が起こる？ → ガウスのつまみと2点標本を動かす → 尤度と少数データの偏り |
| 8 | 未知のつまみを1つに決めてよい？ → 3回表のコインの尤度と事前を重ねる → 事後分布から次を予測 |
| 9–10 | 曲線でも同じことができる？ → ガウスノイズ、係数の事前と事後、曲線の平均を動かす → 不確かさを含む予測 |

最後は冒頭と同じ箱（赤3/4、青1/5、赤の事前3/10）に戻る。オレンジ観測後の赤は45/73、同じ箱から次にオレンジが出る確率は `(45/73)×(3/4)+(28/73)×(1/5)=787/1460≈0.5390`。この予測の和と、曲線での積分は同じ考え方として示す。

## 数値例と原文との対応

- 箱の例は自作です。赤=(リンゴ1,オレンジ3)、青=(リンゴ4,オレンジ1)、赤の事前確率0.3。オレンジの確率は0.365、赤の事後確率は45/73≃0.616438。同じ箱から果物を戻して次に引くオレンジの確率は `box_next_orange()` で計算した787/1460≃0.539041です。
- 連続密度は区間の面積が確率です。変数変換の例は x∼Uniform(0,1), y=2x。幅2、高さ1/2で面積1を保ちます。
- 共分散ゼロと独立を区別します。左右対称な x と y=x²−1 は、共分散がゼロでも独立ではありません。
- ガウスの観測点、二点標本、回帰のノイズと事後標本は `probability_model.py` で再現できます。二点標本の最初の図は見やすい幅の3組を選択し、累積平均は選別せず4,000組を使用します。
- コインの事前は Beta(2,2)、三回表の後は Beta(5,2)。次回の表の確率は5/7。これは原文p.23の説明を具体化した自作例で、1.2でベータ分布の一般論は導出しません。
- 回帰は三次多項式、自作8点、α=0.015、β=1/0.15²。切片も含めて事前を適用し、λ=α/β。最後の帯は予測平均±予測標準偏差であり、観測ノイズだけの帯とは区別します。分散を足し、平方根を取って幅にします。
- 行列 S は係数の事後共分散です。S⁻¹=αI+βΣφ(xₙ)φ(xₙ)ᵀ を用います。PDFの式(1.72)は第2因子の添字が欠けて見えるため、§3.3の式(3.54)とも照合し、訓練入力同士の外積という整合した形で実装・数値検証しています。
- 原文は印刷pp.12–32を抽出・照合しました。この範囲に表はありません。歴史記事、bootstrapの詳細、多変量ガウスの規格化定数の導出は動画では省略しています。

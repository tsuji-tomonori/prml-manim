# PRML 1.6 情報理論

「出やすさを考えて作った符号が、なぜ固定長より長くなる？」を追う日本語動画です。Manim Community、VOICEVOX:WhiteCUL（ノーマル、speaker 23）を使用します。

## 今回の物語設計

冒頭の自作例は4種類のカード A/B/C/D から1枚ずつ出る知らせ。実際の確率は `p=(1/2,1/4,1/8,1/8)` だが、送り手は `q=(1/10,1/5,3/10,2/5)` を信じて `000/001/01/1` を割り当てる。視聴者には固定長2 bitより短くなるか予想してもらい、実際の平均2.625 bitを示す。最後までこの4種類と同じ値を保持する。

| 場面 | 前の疑問から行う実験 | 発見 |
|---:|---|---|
| 1 | 「賢い」符号が長くなる原因を、1回の知らせの意外さで探す | 珍しい結果ほど情報量が大きい |
| 2 | 本当の出やすさで符号を作り直す | 平均1.75 bit。重み付き平均がエントロピー |
| 3 | 候補の多さと出現の偏りを変える | 可能な並び・状態が広がるほど不確かさが増す |
| 4 | カードの代わりに連続値を送る | 測定幅を細かくする分だけ符号が長くなる |
| 5 | 平均と分散しか分からない連続値を試す | 制約下でガウス分布が最大エントロピー |
| 6 | 先に一部を知ると必要な符号を短くできるか試す | 残りの不確かさは条件付きエントロピー |
| 7 | 冒頭の `p` と `q` に戻り、想定ずれの理想符号コストを測る | 交差エントロピーとKLは別の符号を使う余分なコスト |
| 8 | 余分なコストが負にならない理由を曲線で探す | Jensenの不等式。`q/p` の重み付き平均は1 |
| 9 | 本当の確率を知らない場合に観測から想定を直す | 負の対数尤度の最小化が学習につながる |
| 10 | 共有する情報を測り、冒頭の4枚へ戻る | 冒頭の2.625 bitが、本当の確率の符号なら1.75 bitへ下がる |

整数長の冒頭の2.625 bitと、理想長で計算する交差エントロピー約2.624 bitは区別する。後者とエントロピー1.75 bitの差は約0.874 bit（KLは約0.606 nat）。

## 原文との対応と条件

原文PDFの印刷pp.48–58（PDFの68–78ページ）をテキスト抽出して照合し、図1.30・1.31も画像で確認しました。本節に表はありません。原文の8状態の符号例を、独自の4状態 `p=(1/2,1/4,1/8,1/8)` に置き換えています。図を複製せず、図1.30と1.31の数学的構造を自作しています。

- 情報量と符号化はbit、自然対数の説明以降はnat。量子化の2/3/4 bitと最後の共有1 bitには単位を明示します。
- 符号長の一般式 `−ln q` は理想的な平均符号化コスト。1記号の整数長符号が常にエントロピーと等しくなるという主張ではありません。
- 微分エントロピーは画面で `h[p]` と記し、原文の `H[x]` に対応させます。負にもなり、測定単位に依存します。
- ガウス分布の最大性は正規化・平均・分散の固定のもとで述べます。変分法の計算過程は省略しています。
- 条件付きエントロピーと相互情報量は離散版で例示。観測による不確かさの減少は条件について平均した性質です。
- JensenによるKLの説明では、pとqが同じ範囲で正という条件を明示。p>0かつq=0でKLが無限大となる場合も説明します。
- 式(1.119)の標本和には式(1.35)に従って `1/N` を補い、標本平均として表示しています。目的関数の正の定数倍は最適解を変えません。未知の分布とのKLを直接計算したものではありません。

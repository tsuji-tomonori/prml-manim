# PRML 11.1 基本的なサンプリングアルゴリズム

## 物語の設計

全編の問いは「直接標本を引けない二山の分布で、右の小さな山に入る確率をどう測るか」。具体例は $p(z)=0.82\mathcal N(z|-1,0.45^2)+0.18\mathcal N(z|2,0.35^2)$、事象 $z>1$。提案分布 $q(z)=\mathcal N(z|-1,1.4^2)$ から seed 0 で24点引くと、右側は0点になる。視聴者に「右の山の確率も0か」と予想してもらい、実際の確率約0.1796を示す。第10章で分布そのものを近似した問題から、標本で期待値を測る第11章の問いへ渡す。

冒頭と結末は**同じ分布、閾値、24点**を使う。0点という結果は、標本数が足りず重要な領域を見逃したことを示す。逆累積分布による変換は単純な分布なら直接標本を作る。複雑な分布には、提案分布から引いて採否を決める棄却サンプリング、全点を重み付けする重点サンプリング、重みに従って再び選ぶ標本化・重点化・再標本化法へ進む。200点の重点推定と棄却標本を同じグラフに戻し、近づける条件と、外した領域は重みで救えないという限界を示す。次節のマルコフ連鎖モンテカルロ法へ問いを残す。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §11.1、印刷 pp.526–536（PDF pp.546–556）を `pdftotext -layout` で通読。章導入 pp.523–525 も確認。図11.2、11.3、11.4、11.5、11.6、11.7、11.8 をPDF画像で確認した。

[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf) pp.22–23 の訂正を反映する。特に (11.10)–(11.11) は $\ln r^2$、図11.4の赤い曲線は $\tilde p$、(11.17) は接線交点で区切る。本編では誤植の式を再現しない。

節の全項目を列挙する尺にはしない。Box–MullerとCholeskyの導出、ガンマ分布のCauchy包絡の最適化、グラフモデルの論理サンプリングと尤度重み付きサンプリング、Monte Carlo EMの詳細は扱わない。逆変換・棄却・重点・再標本化を一つの例で結ぶための選択である。

## 数値例と近似の条件

- 二山分布は教材用の自作例。成分の重みと正規分布のパラメータは上記のとおり。真の $P(z>1)$ は正規分布の生存関数から計算する。
- 表示する「直接引けない」は**一般的な未正規化モデルに見立てた状況**である。検証用の混合分布自体は成分選択で直接生成できる。この区別を台本・画面に明記する。
- 棄却サンプリングでは $\tilde p=c p$ とし、説明用に $c=1$ を採用する。$k\ge\sup_z p(z)/q(z)$ を数値最大化し、安全余裕を付ける。採択率 $1/k$ は理論値。有限標本の実測率も別に表示する。
- 重点は $w_l=(p(z_l)/q(z_l))/\sum_m(p(z_m)/q(z_m))$。200点は固定seed 11の自作実験。棄却の2000点はseed 1101、再標本化はseed 17。重み付けは候補点に無い領域の寄与を作れない。再標本化は有限点では近似であり、独立な真の標本とは言わない。
- 映像では200点・236採用点を全て同時に描くと重なるため、点の一部を表示し、集計値は全点から計算する。表示範囲は $-4.6\le z\le3.5$ で、面積と確率は全実数で計算する。
- 高次元の $1.01^{1000}$ は原典の等方ガウスの例。1次元の二山分布とは別の思考実験として表示する。

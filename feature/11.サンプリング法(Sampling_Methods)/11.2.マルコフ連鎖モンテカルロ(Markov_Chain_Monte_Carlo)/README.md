# PRML 11.2 マルコフ連鎖モンテカルロ法

## 物語の設計

全編の問いは「11.1で24点が見逃した右の山へ、左の山から歩き始める連鎖はたどり着き、$P(z>1)\simeq0.180$を測れるか」。教材用の同じ二山分布 $p(z)=0.82\mathcal N(z|-1,0.45^2)+0.18\mathcal N(z|2,0.35^2)$ と閾値 $z>1$ を使う。最初に「小さく確実な歩幅なら正確だろう」と予想させ、歩幅0.35の高採択率と右山に入れない初期経路を見せる。現在位置をもとに候補を出し、棄却時は留まる規則を発見する。両方向の確率の釣合いから詳細釣合い・不変分布へ進み、歩幅、初期値、自己相関を同じ分布上の経路と右側推定値で比較する。非対称な提案では逆向き確率の補正が必要だと確かめる。結末は冒頭の二山、開始位置、閾値へ戻り、十分な往来があって初めて右側確率を測れると確認する。

9シーン、8〜13分を目安にする。冒頭の予想と結果は実際に固定seedの数値実験から求める。数式は曲線・経路・方向別の流量と同時に出す。装飾枠、英語の説明文、読み仮名付き字幕は使わない。VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）。

## 原文との照合

Bishop (2006), *Pattern Recognition and Machine Learning* §11.2、印刷pp.537–542（PDF pp.557–562）を `pdftotext -layout` で通読。図11.9と11.10をPDF画像で確認。式(11.33)–(11.45)と[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)のpp.539, 541の訂正を確認した。本文では(11.36)直後の開始添字を$z^{(0)}=0$、(11.45)の両向きの候補密度を訂正後の形で扱う。基底遷移の混合・合成(11.42)–(11.43)の一般論は、物語の核から外れるため詳細な導出は省く。11.3のGibbs標本化は次節に譲る。

## 数値例と近似の条件

- 二山分布は11.1と同じ教材用の自作例。目標密度は評価できるが直接標本化が難しい状況を想定する。ただし検証用の混合模型自体は成分選択で直接生成できる。
- 対称ガウス提案$q(z'|z)=\mathcal N(z'|z,\sigma^2)$を使い、seed 112、開始$z=-1$で歩幅0.35、0.8、2.2を比較する。棄却は現在位置の重複として記録する。右側比率は初期2000歩を除いた10000歩で計算し、独立標本10000点の精度と取り違えない。
- 真の$P(z>1)=0.1796188868$は正規分布の生存関数から計算する。有限経路の比率は固定seedの一例であり、一般的な収束速度・最適歩幅とはしない。
- 高次元の細長いガウスは図11.10に対応する別の説明用例。二山実験の推定値と混ぜない。

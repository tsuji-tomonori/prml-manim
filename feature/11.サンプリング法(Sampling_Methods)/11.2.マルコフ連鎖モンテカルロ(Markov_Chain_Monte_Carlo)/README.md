# PRML 11.2 マルコフ連鎖モンテカルロ法

## 物語の設計

全編の問いは「11.1で24点が見逃した右の山へ、左の山から歩き始める連鎖はたどり着き、$P(z>1)\simeq0.180$を測れるか」。教材用の同じ二山分布 $p(z)=0.82\mathcal N(z|-1,0.45^2)+0.18\mathcal N(z|2,0.35^2)$ と閾値 $z>1$ を使う。最初に「小さく確実な歩幅なら正確だろう」と予想させ、歩幅0.35の高採択率と右山に入れない初期経路を見せる。現在位置をもとに候補を出し、棄却時は留まる規則を発見する。両方向の確率の釣合いから詳細釣合い・不変分布へ進み、歩幅、初期値、自己相関を同じ分布上の経路と右側推定値で比較する。非対称な提案では逆向き確率の補正が必要だと確かめる。結末は冒頭の二山、開始位置、閾値へ戻り、十分な往来があって初めて右側確率を測れると確認する。

9シーン、約8分27秒。冒頭の予想と結果は、乱数の種を固定した実験から求める。数式は曲線・経路・方向別の流量と同時に出す。装飾枠、英語の説明文、読み仮名付き字幕は使わない。VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）。

## 数値例と近似の条件

- 二山分布は11.1と同じ教材用の自作例。目標密度は評価できるが直接標本化が難しい状況を想定する。ただし検証用の混合模型自体は成分選択で直接生成できる。
- 対称ガウス提案$q(z'|z)=\mathcal N(z'|z,\sigma^2)$を使い、乱数の種112、開始$z=-1$で歩幅0.35、0.8、2.2を比較する。棄却は現在位置の重複として記録する。11.2の冒頭の24歩は、11.1で提案分布から独立に引いた24点とは別の標本列である。右側比率は初期2000歩を除いた10000歩で計算し、独立標本10000点の精度と取り違えない。
- 真の$P(z>1)=0.1796188868$は正規分布の生存関数から計算し、独立な数値積分と照合する。歩幅0.35、0.8、2.2の初到達は順に1183、421、37歩。採用率は0.7363、0.5315、0.2888。初期2000歩を除いた右側比率は0.4492、0.1920、0.1786。右側の指示関数の隣接相関は0.9986、0.9787、0.8085。有限経路の比率は固定した乱数の種で得た一例であり、一般的な収束速度・最適歩幅とはしない。結末の緑の矢印は実際の37歩目の初到達（$-1.116931$から$1.687406$）を示す。
- シーン7の右寄りの提案は$q(z\prime|z)=\mathcal N(z\prime|z+0.4,1.1^2)$という説明用例。順方向と逆方向を両方掛けた詳細釣合いを数値で照合する。画面の候補点は仕組みを示すために位置を動かしたもので、二山の採用率集計には含めない。
- シーン8の細長い2次元ガウスの楕円は図11.10に対応する模式図であり、二山実験の推定値と混ぜない。長短の幅の比の二乗は原典のランダムウォークの目安であり、動画の二山例で実測した式ではない。

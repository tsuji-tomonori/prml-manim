# PRML 11.5 ハイブリッドモンテカルロアルゴリズム

## 物語の設計

全編の問いは「小さな歩幅しか通らない分布で、遠くの点へ1回の候補で移り、しかも高い確率で採用されるのはなぜか」。11.2のメトロポリス法のランダムウォーク、11.3の条件付き更新、11.4の歩幅を決める難しさを受け継ぐ。説明用の標準ガウス分布で、位置 `z=-2`、引き直した運動量 `r=0.5`、刻み `ε=0.15`、リープフロッグ `L=18` 回とする。冒頭で約 `z'=2.02345` への移動と約 `0.999735` の採用確率を予告し、「大移動と高い採用率は両立しないはず」という予想をほどく。最後に同じ初期値と結果へ戻る。青は位置、黄は運動量と軌道、緑は採用、紫は比較、赤は棄却や誤差。

| シーン | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 | 小刻みの提案で約4も動ける？ → 同じ密度上に出発と到着を見せる → 11.5の問いを立てる |
| 2 | 候補をどちらへ動かす？ → 運動量を足し、2.3のガウス分布を短く復習する → 位置と運動量の組で動く |
| 3 | 山の上り坂で止まらない？ → 密度の山をエネルギーの谷へ裏返す → 位置のエネルギーと運動のエネルギーを交換する |
| 4 | 谷をどう数値的に走る？ → 勾配の小窓と半歩・全歩・半歩を動かす → リープフロッグで曲線をたどる |
| 5 | 軌道上の確率は変わらない？ → 位相空間で等エネルギー線と面積を動かす → エネルギーと体積の保存が鍵 |
| 6 | 離散化の誤差は？ → 刻みを大きくしてずれを比較し、メトロポリスの採否を重ねる → 補正が必要 |

## 視覚補足と章をまたぐ復習

- `p(z)` と運動量のガウス分布を結び付ける直前に、2.3「ガウス分布」の復習カードRを10.733秒入れる。既存の中心と幅のベル図だけを再現し、過去節をimportしない。
- 勾配による力を初めて読む箇所に、3.1「負の勾配」への短い復習カードRと、接線の傾きから逆向きの矢印へつなぐ視覚補足を合計20.400秒入れる。復習では元図と同じ黄を増加の勾配、紫をその逆向きに使い、本編の黄色い力へ引き渡す。
- 位相空間の面積保存は図11.14をもとに、枠を装飾として使わず、領域自体の変形だけを描く。詳細釣り合いは順逆の矢印と採用率を同じ図で説明する。補足と復習の合計は31.133秒で、音声528.867秒の約5.9%。本編の15%以内。

## 原文との照合

Bishop (2006) §11.5、印刷pp.548–554（PDF pp.568–574）、式(11.53)–(11.70)と図11.14の全文・図像を確認。公式正誤表では式(11.62)の第2行の符号、式(11.68)–(11.69)の`min`内の指数の符号が訂正されている。映像では訂正後の関係を使う。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)。

物語の中心は、運動量の導入、ポテンシャルと運動エネルギー、リープフロッグ、体積保存・可逆性、メトロポリス補正、運動量の再標本化。一般の詳細釣り合いの式(11.68)–(11.69)の逐語的証明と高次元ガウスの計算は図で要点を示す。調整法や複雑な分布の実務は扱わない。

## 数値例と近似の条件

1変数の説明用密度は `p(z)=exp(-z²/2)/√(2π)`、`E(z)=z²/2`、`K(r)=r²/2`。`z=-2,r=0.5,ε=0.15,L=18` から `(z′,r′)=(2.0234500048,0.3951971615)`、`H₀=2.125`、`H₁=2.1252653592`、採用確率 `0.9997346760`。採否の一様乱数を説明用に `u=0.5` と固定すると採用される。刻み1.4、18回の別実験では `ΔH=0.1195015910`、採用確率 `0.8873625961`。数値は `hmc_model.py` と `verify_numerics.py` で再計算する。各刻みは厳密な連続時間の力学ではなく、離散近似である。2変数の細長い例は独立なガウス分布で、標準偏差 `(2,0.4)`、初期位置 `(-2,-0.2)`、初期運動量 `(1,0.2)`、刻み0.15、18回。終点は `(1.51556344,-0.13529434)`。幅の比5と二乗25は原典のオーダー比較の目安で、実際の反復回数・計算費用を意味しない。全ての提案の優位を保証する例ではない。図11.14のせん断は幅1.15、高さ1.16、面積1.334の説明用領域。scene07の小グラフの運動量点 `-1.3,0.2,1.0,-0.6` は説明用に固定した位置で、確率標本の代表値ではない。

## 物語の設計

全編の問いは「位置センサーの4回目の表示は3.5なのに、ゆっくり動く物体の位置はなぜ約1.09と推定されるのか」。1次元の位置を5回測る。観測は 0.1, 0.2, 0.5, 3.5, 0.9。冒頭で4回目の3.5を見て予想させ、結末で同じ値とモデルに戻る。測定を疑う理由を勘で済ませず、状態の変化と測定の両方の不確かさから予測・補正を導く。

| 場面 | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 | 3.5が位置か？ → 5回の観測を並べる → 4回目だけ飛び出す |
| 2 | 前節の鎖と何が違う？ → 離散状態を連続位置に替える → 線形動的システムの2つのガウス分布 |
| 3 | 次の位置をどう予測する？ → 前回の幅を状態雑音で広げる → 平均と分散を運ぶ |
| 4 | 測定で何を変える？ → 予測と測定の山を重ねる → 狭い事後分布 |
| 5 | 3.5を何割信じる？ → 測定雑音のつまみを動かす → カルマン利得が補正量を決める |
| 6 | 毎回それで追える？ → 同じ5点に予測・更新を繰り返す → フィルタの4回目は1.09 |
| 7 | 5回目を見た後は？ → 後向きに修正を渡す → 平滑化の4回目は1.05 |
| 8 | 雑音の大きさが未知なら？ → 事後の期待値で残差を集計 → EMでパラメータを学ぶ |
| 9 | ガウスの山で足りないなら？ → 2峰の例と粒子の重み付け → 厳密な閉性の限界と粒子フィルタ |
| 10 | 最初の3.5へ戻る → 同じ観測・同じ雑音設定で計算 → 予測と測定の相対的な幅が答え |

グラフと観測点を消して文章だけを長く置かない。式の項は予測点、測定点、幅へ色で対応させる。結末も冒頭の5点を残す。

## 原文との照合

原典 §13.3 の全文を `pdftotext -layout` で読み、図13.21–13.23をPDF画像で確認した。主要内容は(13.75)–(13.102)の予測・更新・平滑化、(13.105)–(13.116)のEM、(13.117)–(13.121)の粒子フィルタ。線形ガウスの閉性、HMMとの構造的な対応、カルマンフィルタと平滑化を扱う。多次元行列式の詳細導出、全EM更新式、拡張カルマンフィルタの導出は物語に必要な範囲へ絞る。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)のpp.635–646を確認し、初期共分散は $P_0$、平滑化の補正は $\hat\mu_{n+1}-A\mu_n$ とする。[日本語版PRML英文索引](https://ibisforest.org/index.php?openfile=prml-jp-en_index.pdf&plugin=attach&refer=PRML)に合わせ、カルマン利得行列、カルマンスムーザ、粒子フィルタを用いる。原典(13.100)に印刷された $A\mu_N$ は正誤表で $A\mu_n$ に訂正される。動画に出す(13.88)、(13.89)、(13.90)、(13.100)をこの表記と照合した。

## 数値例と近似の条件

1次元で $A=C=1$、状態雑音の分散 $\Gamma=0.04$、測定雑音の分散 $\Sigma=0.64$、初期平均 $\mu_0=0$、初期分散 $P_0=0.64$。5観測は上記の固定値。4回目の予測平均は約0.222、カルマン利得は約0.264、更新後平均は約1.089。5回目を含めた4回目の平滑化平均は約1.051。これらは学習結果や現実のセンサーの較正値ではなく、映像用の固定したモデルとデータから計算する。真の位置は観測していない設定とする。場面5で測定雑音だけを分散0.04へ下げる比較では、4回目の利得は0.6189、フィルタ平均は2.3086となる。場面9の2峰分布と粒子は限界の模式図で、この5観測の事後分布ではない。

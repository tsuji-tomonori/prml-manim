# PRML 13.2 隠れマルコフモデル

Bishop (2006) §13.2、印刷 pp.610–634（PDF pp.630–654）に沿う日本語の新規動画。13.1 と同じ説明用の「乾き／湿り」2状態、留まる確率0.9、雨の確率0.2／0.8を引き継ぐ。Manim Community、VOICEVOX:WhiteCUL（ノーマル、speaker 23、話速1.08、抑揚1.08）。

## 物語の設計

全編の問いは「2日目は雨だった。そこで湿りと見たのに、後から晴れが3日続くと、その日も乾きだったと判断が変わるのはなぜ？」。冒頭の観測列は **晴→雨→晴→晴→晴**。2日目までの観測で湿りの確率は58.4%だが、5日分を見ると同じ2日目の確率は18.3%になる。冒頭では後から起こった天気が過去の状態を変えるのか、と予想してもらう。結末では同じ列、同じ固定パラメータ、同じ2日目を再表示し、未来の観測を条件に加えた推定の差だと確かめる。

| 場面 | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 | 雨の日は湿り？ → 2日目だけで予想し、残り3日を開く → 58.4%が18.3%へ変わる |
| 2 | 何を隠したモデル？ → 前節の2段の鎖を遷移表と放出確率に分解 → 状態は離散、観測は状態から生じる |
| 3 | 2日目までに何が分かる？ → 乾き／湿りの重みを左から運ぶ → 前向き計算で58.4% |
| 4 | 後の晴れは過去へどう届く？ → 右から未来の尤度を戻す → 前後の重みを合わせて18.3% |
| 5 | すべての状態列を調べる？ → 分岐する経路を各時点の2状態へ集約 → 尤度は前向き計算で得られる |
| 6 | 遷移表を知らない場合は？ → 状態・遷移の事後確率を数え直す → EMで期待度数から確率を更新 |
| 7 | 1本の経路を選ぶなら？ → 全経路から、各状態へ来た最良候補だけ残す → ビタビアルゴリズムと周辺事後の違い |
| 8 | 最初の雨の日へ戻る → 同じ観測列・同じ値を再計算 → 事実は固定、条件となる情報が増えた |

軸、目盛り、数値と重なる装飾枠を置かず、観測列と確率棒を最後まで残す。式は状態・遷移・棒へ色で対応させる。

## 視覚補足と章をまたぐ復習

場面4の直前に8.4の積和アルゴリズムを12秒前後で復習し、2本の経路が1点へ合流する様子を現在の状態列に重ねる。復習ラベルは `復習: 8.4`、音声では「八章四節」。場面4で条件付き確率の補足を約10秒、場面6で事後の重みを期待度数に変える図を約12秒入れる。合計は本編の15%以内を目標とする。本文の図を一時置換するカードと、青=入力、黄=計算、緑=結果、紫=事前の配色を使う。

## 原文との照合

原典 §13.2 の全文をテキストで読み、図13.6、13.12、13.16をPDF画像でも確認。公式正誤表のpp.611,616,619,621–630の項目を確認した。動画の前向き・後向き・遷移更新・ビタビの式は正誤表に沿わせる。左から右への生成、前向き・後向き推論、最尤学習、最尤状態列を主題とし、左から右への制約付きモデル、連続観測のガウス放出、数値のアンダーフロー対策、因子グラフからの再導出、13.2.6の拡張は詳細を省く。

## 数値例と近似の条件

固定した定常な説明用モデル。状態の初期確率は各0.5、遷移は `[[0.9,0.1],[0.1,0.9]]`、雨の放出確率は乾き0.2、湿り0.8。観測列は晴→雨→晴→晴→晴。2日目の湿りについて、フィルタリングは0.5842696629、全5日での平滑化は0.1831098010。観測列の尤度は0.035282。丸めは画面表示だけに適用。パラメータは学習結果ではない。学習を示す数値は、同じ列を用いた1回のEM更新として別に明記する。

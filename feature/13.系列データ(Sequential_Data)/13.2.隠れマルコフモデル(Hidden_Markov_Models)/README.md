## 物語の設計

全編の問いは「2日目は雨だった。そこで湿りと見たのに、後から晴れが3日続くと、その日も乾きだったと判断が変わるのはなぜ？」。冒頭の観測列は **晴→雨→晴→晴→晴**。2日目までの観測で湿りの確率は58.4%だが、5日分を見ると同じ2日目の確率は18.3%になる。冒頭では後から起こった天気が過去の状態を変えるのか、と予想してもらう。結末では同じ列、同じ固定パラメータ、同じ2日目を再表示し、未来の観測を条件に加えた推定の差だと確かめる。

| 場面 | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 | 雨の日は湿り？ → 2日目だけで予想し、残り3日を開く → 58.4%が18.3%へ変わる |
| 2 | 何を隠したモデル？ → 前節の2段の鎖を遷移表と出力確率に分解 → 状態は離散、観測は状態から生じる |
| 3 | 2日目までに何が分かる？ → 乾き／湿りの重みを左から運ぶ → 前向き計算で58.4% |
| 4 | 後の晴れは過去へどう届く？ → 右から未来の尤度を戻す → 前後の重みを合わせて18.3% |
| 5 | すべての状態列を調べる？ → 分岐する経路を各時点の2状態へ集約 → 尤度は前向き計算で得られる |
| 6 | 遷移表を知らない場合は？ → 状態・遷移の事後確率を数え直す → EMで期待度数から確率を更新 |
| 7 | 1本の経路を選ぶなら？ → 全経路から、各状態へ来た最良候補だけ残す → ビタビアルゴリズムと周辺事後の違い |
| 8 | 最初の雨の日へ戻る → 同じ観測列・同じ値を再計算 → 事実は固定、条件となる情報が増えた |

軸、目盛り、数値と重なる装飾枠を置かず、観測列と確率棒を最後まで残す。式は状態・遷移・棒へ色で対応させる。

## 数値例と近似の条件

固定した定常な説明用モデル。状態の初期確率は各0.5、遷移は `[[0.9,0.1],[0.1,0.9]]`、雨の出力確率は乾き0.2、湿り0.8。観測列は晴→雨→晴→晴→晴。2日目の湿りについて、フィルタリングは0.5842696629、全5日での平滑化は0.1831098010。観測列の尤度は0.035282。丸めは画面表示だけに適用。パラメータは学習結果ではない。学習を示す数値は、同じ列を用いた1回のEM更新。遷移・出力・初期確率を同時に更新したとき、乾き→乾きは0.900から0.973142、観測列の尤度は0.035282から0.08102935。短い1列への過適合があり得るため、汎化性能の例ではない。

最尤経路を比べる場面だけは晴→晴→雨→晴→雨を使う。同じ固定モデルで、各時点の周辺事後の最多を並べると乾→乾→乾→乾→湿、Viterbiで列全体の確率を最大化すると乾→乾→乾→乾→乾。前者の結合確率は0.002985984、後者は0.006718464。これは冒頭の観測列とは区別して表示する。全ての確率は状態列の全列挙でも照合し、画面では丸める。

実装では前向き重みを毎日正規化し、後向き重みも同じ係数でスケーリングする。画面の状態確率棒は正規化後の値であり、式の $\alpha_n(k)$ は原典の未正規化の同時確率である。後向き重みの棒は2状態間の相対比を見せるため各時点で合計1に描画上だけそろえる。この棒は状態の事後確率ではない。

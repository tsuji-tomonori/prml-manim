## 物語の設計

全編の問いは「今日が雨なのは同じなのに、昨日が晴れなら明日の雨は約54%、昨日も雨なら約70%。なぜ昨日の情報がまだ効くのか」。同じ定常な説明用モデル、同じ2つの観測列を冒頭と結末で使う。第12章で観測の裏に置いた潜在変数を、今度は時間方向へつなぐという章の継承を冒頭で明示する。予想は「今日が同じなら明日も同じ確率」から始める。

| 場面 | 直前の疑問 → 実験 → 発見 |
|---|---|
| 1 | 今日が雨なら昨日は関係ない？ → 晴れ→雨と雨→雨の2列で明日の棒を隠して予想 → 約54%と約70%に分かれる |
| 2 | 独立ならどう予測する？ → 同じ雨の列を無結線のグラフへ → 全日で雨50%。近い日の情報を捨てる |
| 3 | 今日だけを残せば十分？ → 矢印を隣へつなぎ一次マルコフ連鎖へ → 今日が雨なら約64%。条件付き確率と積の式を図へ対応 |
| 4 | 昨日も残せば差を説明できる？ → 二次の矢印を加え、2列の明日の棒を更新 → 約54%と約70%を区別できる |
| 5 | 何日まで覚える？ → 記憶長Mのつまみと条件表のセルを同時に増やす → K^M(K−1)が指数的に増える |
| 6 | 短い記憶で長い流れを表せる？ → 観測の上に隠れた「乾き／湿り」を置き、状態の鎖と観測への矢印を動かす → 状態は一歩先だけを見る |
| 7 | 隠れた状態はどう昨日を伝える？ → 雨・晴れを見て状態の確率を更新し、次へ送る → 同じ今日の雨でも昨日の違いが残る |
| 8 | 冒頭の問いは解けた？ → 同じ2列と同じ値で棒を再現 → 観測は有限次数のマルコフ性を一般には持たない。離散状態なら13.2、線形ガウスなら13.3へ |

式だけの画面を作らず、観測列、遷移矢印、確率棒、表の対応として式を置く。全編を通して枠・台・影のない図にする。

## 視覚補足と章をまたぐ復習

- 場面3の直前に1.2の条件付き確率と積の規則を約12秒で復習する。2つの出来事の共通部分から「前が分かると次の確率が変わる」へつなぐ。元の図は該当コードの色と関係のみ再現する。
- 場面6の直前に9.2の混合モデルを約12秒で復習する。赤・青の成分密度と緑の混合密度を再現し、隠れた選択が観測の分布を決める意味を、時点間の連結へ渡す。復習カードの表示は `復習: 9.2`、音声は「九章二節」。両カードとも本文領域を一時置換し、字幕帯と場面タイトルを残す。
- 場面5の表はK=2から始め、行数が2^Mで、各行の自由な値がK−1個であることを10〜15秒で視覚補足する。合計を本編の15%以内に収める。

独立カードに対応する音声は scene02 beat04–05（21.0秒）と scene06 beat01（10.8秒）。scene05 beat02（12.9秒）は条件表の補足を本文の流れに組み込んだ。合計44.7秒で、全574.07秒の約7.8%。復習・補足の背景は本編と同じで、黄色の細枠は復習ラベルにだけ使う。

## 原文との照合

図13.2–13.5、式(13.1)–(13.6)を原典のページ画像とテキストで確認した。[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)に従い、式(13.1)には先頭の `p(x_1)` を明示し、高次の一般条件表の自由パラメータ数は `K^M(K−1)` とする。[日本語版PRMLの英文索引](https://ibisforest.org/index.php?openfile=prml-jp-en_index.pdf&plugin=attach&refer=PRML)に合わせ、均一マルコフ連鎖、タップ付き遅延線と呼ぶ。定常な均一マルコフ連鎖と、定常だが隠れた状態を持つ説明例を区別する。自己回帰モデルとタップ付き遅延線は原典上の別案として短く扱い、詳細な学習法は次節へ送る。

原典は「観測の一次・二次マルコフ連鎖から、潜在変数の状態空間モデルへ」という順序です。動画ではこの流れを維持し、一次の表の推定手順、自己回帰モデルの係数推定、タップ付き遅延線のネットワーク構造、隠れマルコフモデルの推論・学習の詳細は扱いません。最後の2項目は§13.2以降へつなぎます。

## 数値例と近似の条件

自作の定常な2状態モデル。隠れた状態は「乾き」「湿り」、初期確率は各0.5。各状態に留まる確率0.9、別状態へ移る確率0.1。雨の観測確率は乾きで0.2、湿りで0.8。初期確率は隠れた鎖の定常分布でもある。観測雨の周辺確率は0.5。全て正確な有限和で計算し、画面の百分率のみ小数点以下を丸める。パラメータは学習結果ではない。「晴れ→雨」は0.540449438…、「雨→雨」は0.701242236…、「雨」だけなら0.644。「晴れ→雨→雨」は0.663160083…、「雨→雨→雨」は0.717466785…で、2日の記憶もこのモデルでは厳密ではない。

「均一」は各時点で同じ遷移表を使う条件です。初期分布が定常分布であることは別の条件で、この数値例は両方を満たします。

一次・二次の観測モデルの棒は、上記の固定した生成モデルの条件付き確率をその履歴長で周辺化した値です。図13.3や13.4の一般モデルをデータから学習した結果ではありません。条件表の自由パラメータ数は、各観測がK通りで、全履歴に一般の条件付き確率表を与える場合に限ります。K=2、M=1,2,3,5で2,4,8,32個。数値は`verify_numerics.py`で、状態列の全列挙とも照合します。

9.2の復習に使う2つのガウス形の山は、各重み0.5、中心−1.12と1.12、標準偏差0.72に固定した説明用の図です。雨の2状態モデルの確率ではありません。

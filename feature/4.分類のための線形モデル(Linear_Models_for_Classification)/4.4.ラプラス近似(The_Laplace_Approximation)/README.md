# PRML 4.4 ラプラス近似

非対称な山の頂上から、山全体の面積をどこまで言い当てられるかを追う日本語動画です。Manim Community と VOICEVOX:WhiteCUL を使用します。

## 物語の設計

全編の問いは「頂上を合わせたガウス形で、元の山全体の面積まで予想できるか」。冒頭では自作の非対称な関数 `f(z)` と、その頂上を合わせた赤いガウス形を同じ軸に重ね、面積が同じになるかを予想する。数値積分では元の面積 `Z=1.563198`、頂上と曲率からの見積もり `Z_L=1.505225` と約3.71%の差が出る。頂上だけでは裾を見ていないという違和感を残す。

| 場面 | 直前の疑問から行う実験 | 発見と次の疑問 |
|---|---|---|
| 1 | 同じ山に局所ガウス形を重ね、面積を予想して確かめる | 近いが同じではない。何を測れば幅を決められる？ |
| 2–3 | 正規化定数を伏せてモードを探し、対数の曲率をつまみで変える | モードが中心、曲率の逆数が分散になる |
| 4 | 局所形と元の関数を別々に正規化する | 密度の高さがずれる理由は裾と面積の差 |
| 5–6 | 方向を増やし、ヘッセ行列と行列式を面積に結び付ける | 高さと各方向の幅から積分を見積もれる |
| 7–8 | 同じ面積の発想をモデル証拠へ移し、BICの省略条件を動かす | 最大の高さだけでなく有力な範囲も効く |
| 9 | もう一つの山と裾を見た後、冒頭の同じ `f(z)` と `Z`, `Z_L` へ戻る | 約3.71%の差の理由を確認し、4.5での重みの不確かさへつなぐ |

予想→図の変化→数値の答え→原因という順を保つ。既存の2.3・3.4・1.2の復習、交差微分と行列式の視覚補足は物語中の手がかりとして残す。グラフ背面の装飾枠は置かず、補足と復習の囲みも外して軸と数値の周囲に余白を取る。画面の個数・番号・倍率にはアラビア数字を使う。

## 数値例と説明上の区別

- 一次元の例は `f(z)=exp(-z²/(2×1.1²)) / (1+exp(-(4z+0.8)))`。ガウス事前の正規化定数を省いた、事前と尤度の積に比例する形です。原図のパラメータやデータを複製していません。モードはNewton法、積分は−12〜12の48,001点の台形則で計算し、別の密な格子でも照合します。
- モード0.401033、曲率2.042328、分散0.489637。元の平均は0.707493。積分1.563198、近似積分1.505225（相対差−3.7086%）。正規化後のピークは0.548985と0.570129です。
- 対数での局所的な高さ・傾き・曲率の一致と、正規化後の密度の高さを区別します。大域的な誤差最小化や平均への適合として説明しません。
- ヘッセ行列の補助例は `h(x,y)=(x²+xy+y²)/2`。`x=0`で`y:0→1`とすると横の傾きが`0→0.5`へ変わります。非対角成分は0.5、固有値は0.5と1.5。行列式の例は主軸方向の精度`4,1`から標準偏差`1/2,1`へ変換し、幅の積`1/2`と行列式`4`を区別します。
- 多変数の等高線は回転行列と精度の固有値から計算。正定値が必要で、極大点でも二階微分がゼロになる場合を除きます。固有値0の例ではガウス楕円を描かず、平らな方向の等高線を表示します。
- 高さと幅の例の面積は3.759942→1.253314→2.982888。表示の短冊は近似ですが、数値表示は全実数での解析積分です。
- 証拠の例はガウス形の尤度と有限範囲の一様事前の積を数値積分。幅0.8→0.3、事前幅5→8で、証拠は0.400347→0.150398→0.093999です。
- BICは独立な大標本・固定次元・識別可能な正則モデルと広い事前を想定した粗い簡略化です。原文の大きいほど良いスコアと、通常の小さいほど良いBICを区別。通常の式の最尤点と原文のMAP点は、この大標本条件で漸近的に対応します。データ数のつまみは整数表示に丸め、補正量の計算は連続補間で動かします。
- 二峰の例のモードと曲率も数値計算します。モード間を移す途中の赤線は表示上の補間です。最後の集中実験は `p_n∝f^n` の自作例で、横軸を `sqrt(nA)(z-z₀)` に換算して形を比較します。個別の実データによる事後更新ではありません。
- 正の変数の対数変換ではヤコビアン `1/τ` も表示。ラプラス近似が多峰性・強い非対称性・大域的な裾を捉えにくい点を説明します。

## 2. 検討・判断と原文対応

- 既存版はパネル比較と短いアニメーション後の静止説明が多く、近似の赤線にも実際の三隠れユニットの計算ではない例があった。材料の位置と傾きを動かす実験を中心に9シーンへ再構成した。
- (5.1)から、入力の重み付き和(5.2)、非線形(5.3)、出力の和(5.4)、出力関数(5.5)–(5.7)へ進む。バイアスの定数入力への吸収(5.8)と(5.9)相当の式も表示する。z₀=1を非線形ユニットj≥1と区別した。
- 層数は調整可能な重みの層で数える。線形ユニットだけならアフィン合成へ戻り、狭い隠れ層では自由度も制限されることを説明した。
- Fig.5.1は順伝播、Fig.5.2はスキップ/疎な接続/閉路なしの評価順序へ対応。図の丸が決定的な計算結果であることを示した。
- Fig.5.3は三つのtanh隠れユニットと線形出力の構造を使い、自作41点へ二乗・sin(πx)・絶対値を非線形最小二乗で当てはめた。隠れ出力と重み付き合計を区別し、完成した解の切替を学習過程と呼ばない。段差は明示的なtanh近似で、H(0)=1と定義した。
- 万能近似はコンパクト領域上の連続関数などの条件付きで説明し、段差の一様近似と混同しない。存在定理とデータから重みを探す問題を区別した。
- Fig.5.4では隠れ出力z=0.5と最終出力y=0.5を区別。自作64点と手動重みの例であり、原図の学習結果や最適境界を複製しない。
- §5.1.1の符号反転は入る重み・バイアス・出る重みすべてを反転した後に成立する。途中の補間では関数が変わることを明示。全結合tanh二層ネットワークの一般的な対称性因子2^M M!を示した。特別な重みの重複はREADMEに補足した。
- 本節には表がない。原図の画像やデータは転写していない。

## 5. 読み・表示の修正

全116文のaudio_queryを取得し、全行のspeech/読みを目視で照合した。修正後も全文を再取得し、`reading_check.md`を確認した。追加で修正すべき読みは見つからなかった。

| 誤読 | 修正後 |
|---|---|
| 正に固定 → マサニコテエ | せいに固定 → セイニコテエ |
| 値 → ネ | あたい → アタイ |
| 次の節 → ツギノフシ | 次のせつ → ツギノセツ |
| 角 → カク | かど → カド |
| 総和で割る → ソオワデワレル | 総和でわる → ソオワデワル |

表示文は通常の漢字・数式記号を維持。式の読み、尤度、隠れ層、活性化関数、重み、順伝播、勾配、二値、双曲線正接、恒等関数も照合した。長母音のケエ/セエなどはEngineの音素表記として記録した。

初回/途中の画像確認で修正したもの:

- 空ラベルの数値表示が原点へ集まる問題を、各ノード下の固定アンカーで修正。
- ノード内の文字を白くし、塗りの濃さを下げてコントラストを改善。
- シグモイドを読む場面では縦軸を0–1へ変更。
- 数式ラベルの長い字形変形をフェードによる切替へ変更。
- 強調時の図形拡大をやめ、数値座標や矢印の先端を保つ色の強調へ変更。
- 部分文字列のSVGグループ化で入れ子の式の未分割記号が欠ける問題を、xcolorによるTeX内の色指定で修正。単独画像でも式全体を確認。
- 交換アニメーションのターゲットが早期確定し途中で文字が重なる問題を、時間から上下二つの経路を直接計算する方法で修正。
- trackerの移動と同時に強調を掛けることでupdaterが止まる箇所を修正。動く点と曲線を同じ時計で維持。

- 関数切替を最初の文で完了し、次の文で確定したsigmoid/softmaxの数値を表示。冒頭の式も括弧の高さを抑えて凡例との間隔を確保。

全編レンダリングは計4回実施し、最後の完成MP4を納品する。途中の単独TeXプレビューはxcolor未追加で1回失敗し、追加後に成功した。

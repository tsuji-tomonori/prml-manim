## 3. 検討・判断

- 電池 $B$ と燃料 $F$ が燃料計 $G$ に合流する原典図 8.21 を具体例に選んだ。3 つの矢印の形を比べた後、同じ車と同じ確率へ戻る順序にした。
- 1.2 の条件付き確率だけを章またぎ復習カードにし、8.1 の雨・道・傘は同章の短いつなぎとして再現した。複雑な総和は 4 状態の棒を足す図で補足した。
- 原典の確率表は有理数で保持し、画面の 0.257 と 0.111 だけ小数第 3 位に丸めた。説明用の鎖と子孫の数値条件、扱わない項目は README に明示した。
- [公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf) の p.376 の条件付き積、p.378 の子孫、p.380 の積分下限を確認した。式は訂正後の $p(a\mid c)p(b\mid c)$ を使用した。

## 4. 実施作業と結果

- README に物語の設計、9 場面、視覚補足・復習、原文照合、数値例の条件を記録した。
- `gauge_model.py` と `verify_numerics.py` を作成。$p(G=0)=0.315$、$p(F=0\mid G=0)=9/35$、$p(F=0\mid G=0,B=0)=1/9$ を別計算で照合した。
- WhiteCUL ノーマル、話速 1.08、抑揚 1.08 で 9 WAV を生成した。`reading_check.json` / `.md` に全 126 文の修正前後の読みを残した。
- 枠のない確率棒と矢印図で動画を制作した。プレビューで見つけた棒の文字の重なり、鎖の節点を隠す移動点、0.09・0.72 の表示時差、子孫ラベルと斜め経路の接近、冒頭の結果の早出しを修正した。
- `py_compile`、数値検証、全字幕寸法は通過。字幕 126 文、数式入り 19 文、最大幅 9.926、最大高 0.697。
- `--disable_caching --flush_cache -ql` で全編をレンダリングした。`ffprobe` は H.264/AAC、854 × 480、15 fps、映像 553.061 秒、音声 553.109 秒。`silencedetect` の 3 秒以上の無音は 0 件、`volumedetect` は平均 -26.6 dB・最大 -6.1 dB。全編デコードを通過した。
- manifest・台本・WAV ハッシュ・字幕時刻を照合した。MP4/WAV の 126 文の最小相関 0.999602、最大時刻差 0.021333 秒。9 場面 × 7 ビートの前半・中央・後半と末尾、計 198 フレームを抽出した。全 63 ビートの中央フレームと、予想前後・切り替え・強調の前後を拡大して目視し、意図しない重なりを確認しなかった。

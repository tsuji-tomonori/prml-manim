## 4. 読みと字幕

## 5. 数値・表示の修正

NumPyで予測、誤差、局所感度、外積、勾配の和、重み更新、中心差分、ヤコビ行列、線形近似を計算した。バイアスを含む二層12パラメータのモデルを使う。

|---|---:|
| 3入力例×12パラメータ、中心差分との最大絶対差 | 4.78755923794e-11 |
| 3入力例×2入力×2出力、ヤコビ行列の最大差 | 1.83864035108e-11 |
| softmax開始条件の中心差分との最大差 | 6.23359697194e-12 |
| 全データ勾配の中心差分との最大差 | 1.32888144933e-11 |

| 入力変位s=0.05,0.2,1.1の線形近似誤差ノルム | 0.00114172126, 0.0180487833, 0.453134172 |

分岐の寄与の相殺、入力の連続変位での表示範囲、音声ハッシュと全字幕の対応も検査した。モデル中の第3データを調整し、三つの勾配の矢印を見分けやすくした後に数値検証を再実施した。

最終化の画像確認で次を修正した。

- 連鎖律の符号実験への切り替え時、強調した子ラベルが残る問題を、familyを含めた削除で解消。
- 勾配和から重み更新へ進む際の旧矢印を除去し、軸を更新量の記号へ変更。
- 分岐の下側の重みラベルを線から離し、寄与の矢印を0の目盛りから離した。
- ヤコビ行列の列間隔を拡大し、軸交点付近の最初の目盛り文字を省いた。
- 誤差関数を比較する場面で、表示中の放物線が線形出力＋二乗和であることを明記し、分類用語の意味を短く補足。
- 導入で更新量を示す式を簡潔にし、初出の説明を整理。
- 中心差分の最初の割線が両側の点へ届くよう、線の長さを差分幅に連動させた。

`py_compile` 成功。指定のフルレンダリングを、修正を反映しながら4回実施し、最終版も終了0、97アニメーション（Manim CE 0.20.1）。画像コンタクトシート生成をシステムPythonで試した際にPillowがなく停止したが、指定venvで再実行して成功した。動画のレンダリング失敗ではない。

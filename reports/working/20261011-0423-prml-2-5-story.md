## 2. 要件と判断

| 要件 | 対応 | 根拠 |
|---|---|---|
| 一つの問いと結末での回帰 | 対応 | 同じ60点の中央 $x=0.5$ を冒頭・最後に表示し、単一ガウス、ヒストグラム、カーネル法の見え方を比較した。 |
| 予想、実験、発見の連続 | 対応 | 「中央にも点が出そうか」という予想から、空のビン、幅への依存、局所的な窓、近傍点数へ進む構成を README と台本へ記録した。 |
| 原典との照合 | 対応 | Bishop 原典の印刷 pp.120–127 と公式 errata の式 (2.243)、(2.250) を確認した。 |
| 既存の理解補助 | 対応 | 視覚補足と 1.2・1.5、1.4 の節番号付き復習を残した。 |
| 音声・字幕・動画の更新 | 対応 | 9場面の WAV、manifest、読み確認、480p MP4 を再生成した。 |

中央に観測点が少ない2峰性分布を再現可能な乱数 seed 2509 の60点で示した。$x=0.5$ の密度は真値 0.055246、単一ガウス 1.951526、帯域幅 $h=0.06$ のカーネル推定 0.401519。ヒストグラム幅 0.08 の中央ビン $[0.48,0.56)$ は空である。結末でも同じ点と値を使うため、結果を違う例へすり替えない。比較は同じグラフで曲線を切り替え、ビン幅と近傍点数は画面上の変化と合わせた。グラフ背面の装飾枠は置かず、中央ビンの境界線はデータを示す線として使った。

原典: リポジトリ内 `.working/Bishop-Pattern-Recognition-and-Machine-Learning-2006.pdf`。公式訂正表: <https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf>。

## 4. 検証結果

- `py_compile`、`verify_numerics.py`、`git diff --check` は通過。数値検証は中央の例、正規化、箱型窓とヒストグラムの対応、$k$ 近傍、二項分散、分類を含む。
- VOICEVOX の `audio_query` で124文すべての読みを確認し、誤読しやすい数値と語を `speech` で修正。辞書登録はしていない。自分で起動した Engine は作業後に停止した。
- 台本・字幕・9個の WAV と manifest の文面・ハッシュ・尺の整合を確認。124字幕の最大幅 9.330、最大高さ 0.701 は画面内の基準 12.9、0.9 を下回った。
- 指定の `manim --progress_bar none --disable_caching --flush_cache -ql` で全編をレンダリングし、96アニメーション、終了コード0。`ffprobe` で映像 583.866秒、音声 583.893秒を確認した。
- `silencedetect`（-45 dB、3秒以上）の該当0件。`volumedetect` は平均 -26.6 dB、最大 -5.8 dB。音声・映像の全編デコードは終了コード0、エラーログ0バイト。
- 最終動画から場面の前後、強調・移動・色替えの途中を含む184フレームを抽出。うち53フレームを目視し、字幕と対象図形の同時表示、軸・式・ラベルとの重なり、枠の有無を確認した。直前の全編レンダリングから最終変更で変わった10フレームは全件目視し、残り174フレームの画素ファイルが同一であることを確認した。レビュー用フレームは Git 管理外に置いた。

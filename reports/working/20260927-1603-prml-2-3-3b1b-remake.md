| 論点 | 内容への反映 |
|---|---|
| ガウスの定義 | 密度と区間確率、平均・標準偏差・分散を区別 |
| 中心極限定理 | 独立・同分布・有限分散の一様乱数例。標準化した平均の極限を説明 |
| 多変量の幾何 | 等密度輪は固有分解で計算。Δ=1の半軸は√λ、密度比exp(−1/2)。白色化も可逆な同じ写像 |
| 共分散制限 | 平均込みの一般D(D+3)/2、対角2D、等方D+1。ガウスにおける無相関と独立 |
| 条件/周辺 | 水平切断の正規化と全高さの積分を分離。条件共分散は観測値に依存しない |
| 線形ガウス | 順方向の分散伝播、観測からの事後、精度行列を使う一般式 |
| 最尤/逐次 | 不偏性は反復平均の性質。式2.126を同じデータの標本平均と照合 |
| ベイズ | 既知分散での平均の事後と、既知平均での精度の事後を明確に切り替える |
| t分布 | ガンマ精度の積分、固定自由度でのMLE。λと逆分散を区別、有限分散はν>2 |
| 周期変数 | atan2で象限も考慮し、平均ベクトルゼロなら未定義。極座標図の面積を確率とは扱わない |
| 混合 | πの制約、負担率、単一ガウスとの比較。混合の図は生成パラメータでありEM学習の結果とはしない |

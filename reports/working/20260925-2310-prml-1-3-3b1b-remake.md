## 3. 検討・判断

原文の中心は、検証・テスト、交差検証、組合せ探索の計算量、AIC、ベイズ的比較への予告だった。
多数の静止パネルを並べず、同じ座標で曲線と評価点の役割を変える構成にした。
多項式次数をdと表記し、式(1.73)のM（調整可能なパラメータ数）との混同を避けた。
ガウスノイズの分散を既知として固定し、対数尤度を数値化。推定する係数はd+1個である。
訓練・検証の誤差はMSEに統一し、CVでは等しい組のMSEを平均する。

1.1の `narration_content.py`、読み確認スクリプト・一覧、字幕描画、音声生成・同期、
20260925の再制作・音声同期・読み修正・字幕サイズ・公開レポートを参照した。
共通化は節内の `scene_support.py` とし、他の節の実装を変更していない。

## 4. 原文との対応

| 原文 | 内容・反映 |
|---|---|
| p.32 冒頭 | 次数・正則化による複雑さ、未知データの予測を目的とするモデル選択 |
| p.32 第2段落 | 訓練性能だけでは汎化を判断できない。検証で選択し、反復設計で検証にも過学習しうる。別テストで最終評価 |
| pp.32–33 / Fig.1.18 | 4組の担当を回し、毎回残りの18点で再学習。6点の評価誤差を平均。学習割合(S−1)/S |
| p.33 / S=N | 一点を残すleave-one-out。24点なら23点で24回の学習 |
| p.33 / 計算量 | 5×4候補×4分割=80回。さらに3候補で240回。全探索の一般形S k^h |
| p.33 / Eq.(1.73) | ln p(D\|wML)−Mを最大化。既知分散でM=d+1。通常AIC=−2ln p+2Mの最小化との同値性 |
| p.33 最終段落 | パラメータ不確かさの限界、BICの§4.4.1とベイズ的モデル比較の§3.4への予告 |

1.3に表はない。MSE式とガウス対数尤度の展開は説明用で、1.3の番号付き式とはしていない。
p(D|wML)は尤度、その対数が対数尤度である。原文本文の表現をそのまま混同していない。
既知の分散を推定パラメータとして数えず、未知分散を同時推定する設定とは区別した。
末尾の曲線群は模式図と字幕・凡例・音声で明示し、事後分布の標本とはしていない。

## 6. 制作中に見つけた問題と修正

- グラフ切替時に、個別に追加した点・軸が残存した。切替時に画面を明示的に消去して再構成した。
- CV候補比較に旧グラフの目盛りが残った。各子オブジェクトと目盛りを除去した。
- CV平均の分数と学習割合の分数が接近した。平均式を一段にし、表示間隔を確保した。
- AIC説明の式の切替で重なる可能性があった。前の式を除去後、新しい説明式を表示した。
- 終盤の模式曲線群が残った。グループの子も含めて除去した。
- 6分割へ変える際も、その分割による実際の学習曲線と評価点の色へ更新した。
- 全データ再学習へ進んだ後も23点と表示していた問題を、24点に修正。分割の切替式の重なりと終盤の凡例も修正した。
- 探索格子の三層表示は前の面を隠す塗りにし、重なった線の過密を減らした。

## 3. 検討・判断

- 「測定値を8個増やしたのに近所の仲間が消えた」を全編の問いとした。分類と無関係な座標を足す自作例を固定 seed で作り、2座標では A=22、B=12、C=0、10座標では全色0と実測した。結末でも同じ点と箱を使う。
- scene02 の5分割格子は増加の仕組みを示す別実験と明記した。冒頭の幅0.4の箱と混同しないようにした。
- 原典の係数数、球殻比、ガウスの半径密度、画像の低い自由度を、冒頭の疑問から生じる順に配置した。高次元の球を無理に3D化せず、式と次元つまみで量を示した。
- 1.2 の復習と半径密度の補足は説明の手がかりとして残し、グラフ背面の装飾枠を外した。字幕では記号とアラビア数字を使い、読みは `speech` に置いた。

## 4. 実施した作業と検証

- main 更新後、`codex/prml-1-4-story` の worktree を作成。README に物語設計を先に記録し、台本、数値モデル、Manim、VOICEVOX 音声、480p15 動画を更新した。
- VOICEVOX Engine 0.25.2 を必要時に起動し、WhiteCUL ノーマル 23、話速1.08、抑揚1.08で合成。全129文の読みを確認し、誤読を `speech` で修正。自分で起動した Engine は停止した。
- `py_compile` と `verify_numerics.py` の5群に合格。90点の近所、格子、係数、球殻、ガウス、画素、WAV・台本ハッシュを確認した。9シーン、64 beat、129字幕の時刻差は最大 `5.7071e-11` 秒。
- 指定のキャッシュ無効コマンドで全編をレンダリングし、108アニメーションを記録。ffprobe は H.264 / AAC、854×480、15fps、映像641.995767秒、音声642.026667秒。WAV 合計642.000000秒。映像と音声の尺の差は0.030900秒。
- `silencedetect=noise=-45dB:d=3` で3秒以上の無音0件。音量は平均−26.6dB、最大−5.9dB。全編の映像・音声デコードはエラーなし。
- 全129字幕を組版し、最大幅9.345313、高さ0.699531。最終動画の59フレームで全9シーン、強調・移動・色替えの途中と直後、字幕・式・点・ラベルの重なりを目視した。レビュー用フレームは Git 管理外に保存した。

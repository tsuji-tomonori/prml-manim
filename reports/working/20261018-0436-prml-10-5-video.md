## 3. 実施作業

1. main を更新し、`.working/worktrees/prml-10-5-video` に `codex/prml-10-5-video` を作成。設計を README に先に記録し、commit/push した。
2. 原典PDFの印刷pp.493–498を `pdftotext -layout` で読み、図を画像で確認。[Microsoft Research の公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)も確認した。
3. 真のガウス平均と Jaakkola–Jordan 型下界の独立な積分、解析式、点ごとの不等号、接点、最適化を実装した。`E[σ(a)]=0.647726439`、`ξ≈2.331913`、`F(ξ)≈0.599663413`。
4. 8シーン・64拍・128文の台本、8本の WAV、読み監査ファイル、字幕と同期する Manim 映像を制作した。作業中に自分で起動した VOICEVOX Engine は停止した。
5. 全編レンダリング後、主グラフと小グラフの軸名の重なり、シーン5の切り替え中の塗りの崩れを修正し、音声変更後に再び全編をレンダリングした。

## 5. 検証結果

- `py_compile`、数値検証、台本・字幕・WAVのハッシュと尺、全128字幕の寸法を確認。最大字幕幅10.295、最大高さ0.619で画面内に収まった。
- 音声変更後、Manim を `--disable_caching --flush_cache -ql` で全編再レンダリングした。`ffprobe` で854×480、15 fps、映像559.667秒、音声559.701秒を確認。
- `silencedetect` で3秒以上の無音0件。`volumedetect` は平均−26.7 dB、最大−6.2 dB。完成MP4の全編デコードに成功。
- 元WAVと完成MP4音声の128文すべてを照合し、最小相関0.99955、最大時刻差0.0214秒。場面の時刻誤差は最大約3.7×10⁻¹¹秒。
- 392フレームを抽出し、25枚の一覧を生成。このうち12枚の一覧と複数の拡大フレームを目視し、強調・移動・色替えの途中と直後、軸名・目盛り・注記・字幕の読みやすさを確認した。最終フレームでは3つの値と小グラフの軸名が読める。
- `git diff --check` を通した。レビュー画像・プレビュー・`__pycache__` は Git 管理対象に含めていない。

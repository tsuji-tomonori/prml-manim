## 3. 検討・判断

- 原典の画像復元例を、固定した H 字形の二値画像で具体化した。14 画素を反転し、行 5・列 5 の白い穴を全編の問いにした。観測と隣接画素の衝突を無向グラフの分離、局所因子、エネルギーで解く順にした。
- 8.2 は同じ章なので短い言葉でつなぎ、1.2 の正規化だけを章またぎ復習カードにした。総和・クリーク・指数は図と同じ画面で示し、本文の 2 候補比較を補足で引き延ばさなかった。
- ICM の結果は固定データと $h=0,\beta=1,\eta=2.1$ に限る。原典図 8.30 の 96%・99% を自作画像の結果として使わず、原典の正誤表の p.390 の図ラベルと `max-sum` の訂正も README に記した。
- レビュー用レンダリングで見つけた画像全体の意図しない色替え、復習カードの注記と枠の接近、総和記号の小さい字幕を修正し、指定コマンドで全編を再レンダリングした。

## 4. 実施作業と結果

- README に物語の設計、9 シーン、補足・復習、原文との照合、数値条件、再生成手順を記録した。

- VOICEVOX Engine 0.25.2 の既存プロセスを使い、WhiteCUL ノーマル、話速 1.08、抑揚 1.08 で 9 WAV を生成した。`reading_check.json` / `.md` に全 126 文の読みと修正履歴を保存した。自分で起動した Engine はない。
- `py_compile`、数値検証、全字幕寸法を通過。字幕 126 文、数式入り 7 文、最大幅 9.953、最大高 0.619。画面説明文の日本語、数値のアラビア数字、グラフ背面の装飾枠なしを確認した。

- manifest・台本・WAV ハッシュ・字幕時刻を照合した。MP4/WAV の 126 文の最小相関 0.999480、最大時刻差 0.021333 秒。261 フレームを抽出し、全 63 ビートの中間と動きのある 21 ビートの開始・序盤・終盤、計 126 代表フレーム以上を目視した。復習カード、数式字幕、近傍強調、棒、画素更新、道徳化の線を拡大し、意図しない重なりを確認しなかった。

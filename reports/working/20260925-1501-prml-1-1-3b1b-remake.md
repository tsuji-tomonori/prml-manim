## 3. 原文を読んで判断したこと

本体側 `.working/Bishop-Pattern-Recognition-and-Machine-Learning-2006.pdf` を `pdftotext -layout` で抽出し、印刷 pp.1–12 の本文・図キャプション・式・表を確認した。手書き数字の Fig.1.1 は今回の映像から省き、p.2 の汎化、p.3 の回帰を冒頭の問いへ組み込んだ。

| 原文 | 確認内容と反映 |
|---|---|
| pp.4–5 / Fig.1.2 | sin(2πx)＋Gaussian noise、学習に使うのは観測点。緑の線は比較用 |
| p.5 / Eq.(1.1) | M は次数、係数は M+1 個。M 自体を非整数の次数として説明しない |
| pp.5–6 / Eq.(1.2), Fig.1.3 | r=y−t、E=Σr²/2。独立した ±1 の説明例から、実残差の面積へ進む |
| p.6 | 誤差は係数について二次関数。等高線は実際の二次形式から計算。経路は説明用で、勾配降下法の反復とはしない |
| pp.6–8 / Fig.1.4–1.5, Eq.(1.3) | 全点を通ることと汎化を分ける。RMS は残差から計算し、正則化項を含めない |
| pp.8–9 / Table 1.1 | 同じ単項式基底で係数を比較。棒は符号付き log₁₀(1+|wⱼ|)。係数だけで過学習を普遍的に判定しない |
| p.9 / Fig.1.6 | 元の点を保持して N を増やす。1点追加ごとの単調改善は主張しない |
| pp.10–11 / Eq.(1.4), Fig.1.7–1.8, Table 1.2 | 式どおり w₀ も含めて正則化。λ=exp(ln λ)>0。ln λ=−32 を無正則化と同一視しない |
| p.11 | M と λ を選ぶには検証データが必要。動画の test 曲線は現象観察用 |
| pp.5,12 / §1.2 | 観測ノイズと有限データによる不確かさを区別。帯は既知ノイズ ±2σ であり、学習した曲線の信頼区間ではない |

正則化を拡大最小二乗で解き、正規方程式による条件数の悪化を避けた。全グラフ、係数、RMS は NumPy の計算結果から描く。PRML の図・係数を転写していない。

## 6. 数値検証

訓練 seed=2、テスト seed=17、追加点 seed=6、ノイズ σ=0.25。訓練10点、独立テスト100点。図中のテスト残差は代表10点、テスト RMS は100点で計算する。

| 条件 | 訓練 RMS | テスト RMS |
|---|---:|---:|
| M=0, N=10 | 0.600660 | 0.734581 |
| M=3, N=10 | 0.247170 | 0.316383 |
| M=9, N=10 | 2.30×10⁻¹¹ | 0.721531 |

M=9 固定で N=15 の test RMS は 0.483751、N=40 は 0.273024、N=100 は 0.272972。
描画前の追加点の検討では N=15 で悪化する乱数例も確認した。最終映像は教材として N=10→15→100 の改善を追いやすい再現可能な例を採用し、一般に単調改善するという主張はしていない。

`verify_numerics.py` の5検証が合格:

1. 訓練最小二乗誤差の非増加、M=9 の全点補間、RMS と Eq.(1.3)、次数間の係数補間。
2. 正則化解が Eq.(1.4) の停留条件を満たし、w₀ も正則化されること。
3. 追加データが元の10点を保持、N の整数位置の再フィット、等高線のエネルギー差。
4. 表示範囲: 次数0〜9、N=10〜100、ln λ の321位置で、2001個の x における曲線値を検査。範囲外なし。
5. ローカルの人工 PCM fixture による音声の余白・台本/WAVハッシュ・manifest 保存と再開・不整合 WAV の除去。これは VOICEVOX の実音声合成・聴取検査ではない。

数式の中心は、一般に成り立つ $E_{\rm COM}\leq E_{\rm AV}$ と、誤差が無相関のときに限る $E_{\rm COM}=E_{\rm AV}/M$ の違い。ブートストラップで作った5本に無相関性を仮定せず、別の説明用誤差関数で5分の1の条件を見せた。原典の逐行の式変形は、問いに必要な図解に置き換えた。1.2の既存動画ではブートストラップの詳細を扱わないため、同操作は復習扱いにせず視覚補足として導入した。

## 3. 実施した作業

- `git fetch origin && git switch main && git pull --ff-only` の後、`.working/worktrees/prml-14-2-video` に `codex/prml-14-2-video` worktreeを作成した。設計、数値と音声、読み修正、映像、検証を目的別にcommit・pushした。
- PRMLの対象3ページ、関連する§3.2と§1.2.3、[公式正誤表](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/05/prml-errata-1st-20110921.pdf)、14.1と1〜5章の手本を確認した。
- 自作回帰例を固定seedで再現した。冒頭の5予測は0.785935〜1.111694、平均0.965409、生成関数の値0.948526。501点の離散入力分布で個別平均二乗誤差0.084512、コミッティ0.025843、比0.305793。差0.058669は予測間の散らばりと一致した。
- 8シーン・64 beat・128文の台本とWhiteCULの8 WAVを制作した。speaker 23、話速1.08、抑揚1.08。全128文のVOICEVOX読みを確認し、小数や「負」の誤読を`speech`の表現で修正した。VOICEVOX Engineは既に起動していたため、自分では起動・停止していない。辞書登録はしていない。
- 音声の変更後に`--disable_caching --flush_cache -ql`で全編をレンダリングし、字幕・音声・動画を検証した。
